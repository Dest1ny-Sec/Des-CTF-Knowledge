# 2024 极客少年 WP

## Reverse 1: little re

```python
sbox = [get_wide_byte(0x403040+i) for i in range(320)]
v5 = [0x18, 0x10, 0xcf, 0xe6, 0x16, 0x5b, 0x4e, 0xe6, 0x2c, 0x87, 0x91, 0x92, 0x1b, 0xaa, 0x8, 0xee, 0xd6, 0x70, 0x74, 0x42, 0xe9, 0x7, 0x7, 0x46, 0xd6, 0x16, 0x2a, 0x42, 0xfa, 0x6c, 0x89, 0xe7, 0x2d, 0x29, 0x53, 0x60, 0xc5, 0xa, 0x4d, 0x53, 0xc5, 0x15]
l = []
for i in range(len(v5)):
    l.append(chr(sbox.index(v5[i]) ^ i))
print(''.join(l))
```

`get_wide_byte(0x403040+i)` 读 sbox 320 字节表，`v5` 41 字节密文逐位 `sbox.index(v5[i]) ^ i` 还原。

## Reverse 2: BeautifulFlower

主函数核心（Line 17-21）是 XOR i。花指令让比较 `cmp [rsp+30h+var_10], 30h; jge` 不直接走 `cip[i]==str[i]` 形式。

动态调试 Tab 读汇编：
```
movsxd  rcx, [rsp+30h+var_10]      ; rcx = i
mov     rax, 0F1A07B55C59324ABh     ; sbox1 base
add     rax, cs:off_7FF674ACB048
movsx   eax, byte ptr [rax+rcx]     ; sbox1[i]
movsxd  rdx, [rsp+30h+var_10]      ; rdx = i
mov     rcx, 0CB9460C9C81AB45h      ; sbox2 base
add     rcx, cs:off_7FF674ACB050
movsx   ecx, byte ptr [rcx+rdx]    ; sbox2[i]
cmp     eax, ecx                    ; sbox1[i] == sbox2[i]
```
两个 sbox 读出来 + 异或 i 即得 flag。
