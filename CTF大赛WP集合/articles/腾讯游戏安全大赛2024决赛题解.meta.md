## 关键考点

### WPOFFx64 + WPONx64
```c
KIRQL WPOFFx64() {
    KIRQL irql = KeRaiseIrqlToDpcLevel();
    UINT64 cr0 = __readcr0();
    cr0 &= 0xfffffffffffeffff;  // 关闭CR0第16位WP
    __writecr0(cr0);
    _disable();
    return irql;
}

void WPONx64(KIRQL irql) {
    UINT64 cr0 = __readcr0();
    cr0 |= 0x10000;  // 恢复CR0第16位WP
    _enable();
    __writecr0(cr0);
    KeLowerIrql(irql);
}
```
- KeRaiseIrqlToDpcLevel升IRQL到DPC级别(屏蔽中断)
- CR0第16位WP位控制写保护
- _disable()禁用中断

### inline hook
```c
char newcode[] = {
    0x48,0xB8,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,  // mov rax, [target]
    0xFF,0xE0  // jmp rax
};
```
- 12字节(包含mov rax+addr+jmp rax)
- 5字节覆盖原函数入口(jmp+rel32)或12字节(mov rax+abs+jmp rax)
- oldcode备份原指令

### Hook/Unhook函数
```c
NTSTATUS Hook() {
    KIRQL irql = WPOFFx64();
    for (int i = 0; i < sizeof(newcode); i++) {
        target[i] = newcode[i];
    }
    WPONx64(irql);
    return STATUS_SUCCESS;
}

NTSTATUS Unhook() {
    KIRQL irql = WPOFFx64();
    for (int i = 0; i < sizeof(newcode); i++) {
        target[i] = oldcode[i];
    }
    WPONx64(irql);
    return STATUS_SUCCESS;
}
```
