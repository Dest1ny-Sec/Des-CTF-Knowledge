## 2. 找不到的 p 和 q（朴素 RSA）

```python
from Crypto.Util.number import bytes_to_long, inverse, getPrime
from flag import flag
m = bytes_to_long(flag)
p = getPrime(1024)
q = getPrime(1024)
n = p*q
e = 65537
c = pow(m, e, n)
pq = p*(q-1)
qp = q*(p-1)
print("c=", c)
print("n=", n)
print("pq=", pq)
print("qp=", qp)
```

**关键**：题目给了 `pq = p*(q-1)`，直接 `gcd(pq, n) = p`，p 拿到后 q = n / p：

```python
from Crypto.Util.number import *
p = GCD(pq, n)
print(long_to_bytes(pow(c, inverse(65537, p-1), p)))
# b'flag{719014b3-c4e1-4f81-a7be-b4f0d65c9e10}'
```

## 4. special DH（小 p 爆破）

```python
p = 65537
g = 5
c1 = 19; c2 = 47; c3 = 101
A = 0x7F2; B = 0x2A3D

def modinv(x, p): return pow(x, p-2, p)
def compute_special_dh_key(B, a, p, c1, c2, c3):
    part1 = (pow(B, a, p) * c1) % p
    part2 = (part1 + c2) % p
    inv_c3 = modinv(c3, p)
    return (part2 * inv_c3) % p

# 爆破 a
for a in range(p):
    if pow(g, a, p) == A:
        print(a)  # 找到 a
        print(compute_special_dh_key(B, a, p, c1, c2, c3))
        break
```

p 很小（65537）→ 直接爆破 Alice 私钥 a。
