# 2023 第七届蓝帽杯半决赛电子取证参考 WP

> 注：原文以答案列表形式罗列 15 题，缺少详细步骤，仅给出关键字段。

**检材描述**

嫌疑人删除通话/短信前用同伙 APK `com.example.myapplication` 读 contacts.db 备份。

**关键答案**

| 字段 | 值 |
|------|-----|
| 时间 | 09-11 17:21 |
| 镜像版本 | sailfish 24.32 |
| IMEI | 352531082716257 |
| 数据文件 | contacts.db |
| 记录数 | 100 |
| 包名 | com.example.myapplication |
| 算法 | SHA256 |
| Activity | com.example.myapplication.mainactivity |
| 编码 | BASE64 |
| 数字 | 3 / 2 / 2 |
| 密码密文 | bglqdwjkewhmdxjp |
| 字节数 | 9250 |

**复现思路**

1. 加载安卓镜像 + APK 文件
2. jadx 反编译 com.example.myapplication 看 mainactivity
3. 静态分析读 `content://contacts/...` 或 `data/data/com.example.myapplication/databases/contacts.db`
4. 时间戳、版本、IMEI、数据库大小等基础字段直接 dump
5. 算法 SHA256 + BASE64 双层哈希需要看 APK 源码确认
