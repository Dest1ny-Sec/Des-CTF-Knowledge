# 2026 天府杯 pwn 0 解题目 WP

> libc 版本：**2.27**（经典堆漏洞版本）

## 题目结构

```c
extern FILE *stderr;
extern FILE *stdin;
extern FILE *stdout;

unsigned int main(unsigned int a0, unsigned long long a1) {
    unsigned long long v0;  // [bp-0x28]
    unsigned int v1;        // [bp-0x1c]
    char result;             // [bp-0x11]
    unsigned long long v3;   // [bp-0x10]
    
    v1 = a0;
    v0 = a1;
    setvbuf(stdout, NULL, 2, 0);
    setvbuf(stderr, NULL, 2, 0);
    setvbuf(stdin, NULL, 2, 0);
    result = 0;
    
    while (true) {
        mean();
        v3 = input();
        if (v3 == 1) {
            add(sub_400b7f);
        } else if (v3 >= 1) {
            if (v3 == 2) {
                show(sub_400bea);
            } else if (v3 == 1337) {
                if (result) return 0;
                show(sub_400ccd);
                result = 1;
            }
        }
    }
}
```

## 关键点

1. **setvbuf 关闭缓冲** → 标准 I/O 直写
2. **`mean()` + `input()` 菜单** → 输入选项 1/2/1337
3. **add(0x400b7f)** + **show(0x400bea)** + **show(0x400ccd)** 三个子函数
4. **`result` 全局标志**：第一次进 1337 → result=1 → show sub_400ccd；第二次进 1337 → result=1 → 直接 return 0 退出
5. **while(true) 循环** → 但 result=1 后只能从 1/2 进入

## 0 解分析

- 题目难度极大，48h 比赛 0 队伍提交
- libc-2.27 经典 tcache 攻击（tcache 头指针堆 0x250 位置）
- House of Apple 2（IO_FILE 链劫持）
- pwndbg 调试 + tcache 攻击 + libc 2.27 经典 house 系列
