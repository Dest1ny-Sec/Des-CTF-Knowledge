# 2025 能源网络安全大赛团体预赛 eazy_crypto

## 题目

```python
from secret import flag
from Crypto.Util.number import getPrime

flag = bin(int.from_bytes(flag, 'big'))[2:]

private_key = []
g = getPrime(10)
private_key.append(g)
for i in range(len(flag) - 1):
    g = g * 2
    private_key.append(g)

a = getPrime(20)
b = getPrime(len(flag) + 20)
public_key = []
for i in private_key:
    public_key.append((a * i) % b)
print(public_key)

c = 0
for i in range(len(flag)):
    c += int(str(flag)[i]) * public_key[i]
print(c)
```

**给**：
- public_key（80+ 个）
- c（密文）
- x, y（用于 b = 2*x - y）

## 攻击

### 1. 求 b
```python
b = 2 * x - y
assert is_prime(b)
```

### 2. 求 a
```python
from sympy import factor
a = factor(public_key[0])[1][0]  # factor first public_key 找到 a 的因子
```

### 3. 还原 super-increasing private_key

LLL 还原超递增序列：
```python
from sage.all import *
def lll_recover_super_inc(public_key, b, a):
    n = len(public_key)
    M = matrix(ZZ, n+1, n+1)
    for i in range(n):
        M[i, i] = 1
        M[i, n] = public_key[i] * pow(a, -1, b) % b
    M[n, n] = b
    L = M.LLL()
    # 找还原的 private_key
```

简单方法：直接 mod b 求逆
```python
a_inv = inverse(a, b)
private_key = [(pk * a_inv) % b for pk in public_key]
```

### 4. 贪心解子集和

private_key 是超递增序列 → 贪心从大到小：
```python
flag_bits = []
c_remaining = c
for i in range(len(private_key) - 1, -1, -1):
    if c_remaining >= private_key[i]:
        flag_bits.insert(0, '1')
        c_remaining -= private_key[i]
    else:
        flag_bits.insert(0, '0')
flag_bin = ''.join(flag_bits)
flag = int(flag_bin, 2).to_bytes((len(flag_bin) + 7) // 8, 'big')
print(flag)
```

## 关键 takeaway

- 背包密码 = super-increasing + 模 b 乘 a 混淆
- 攻击：gcd(public_key[0], b) 找 a 因子 / 因式分解 → a_inv → private_key mod b
- 超递增序列 → 贪心解子集和 O(n)
- a、b 必须是质数，否则用 lattice attack（LLL）
