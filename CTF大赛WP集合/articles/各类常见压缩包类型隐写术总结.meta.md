# 各类常见压缩包类型隐写术总结

## 概览
- **来源**: ctfiot 85067
- **类型**: 压缩包隐写综合
- **难度**: ⭐⭐

## 8 种技巧

### 1. 识别文件头
- **zip**: `50 4B 03 04` (PK)
- **rar4**: `52 61 72 21 1A 07 00`, 尾 `C4 3D 7B 00 40 07 00`
- **rar5**: `52 61 72 21 1A 07 01 00`

### 2. 爆破 (ARCHPR)
- 6 位纯数字
- 生日日期字典
- 姓名首字母
- 工具: ARCHPR

### 3. 伪加密
- zip 标志位: 奇数=加密, 偶数=未加密
- 位置: `504B0304` 后的标志字节
- 010editor 模板修

### 4. CRC32 碰撞
- 10 字节内可逆
- 例子:
  - 0x292b7c58: K9Qt3R/OpaH_9/.../hxb_/pAgb_0
  - 0xee8d8709: .../th1s_/...
  - 0x5ca2e8e5: .../secret/...
- 拼接: `th1s_hxb_secret`

### 5. 已知明文攻击
- 同一 zip 内所有文件用同一 key
- 3 个 32-bit key 96 bit
- 工具: Advanced Archive Password Recovery / bkcrack
- 12 字节差异 = 3 key
- 例: 富婆通讯录.png + 加密 zip 拿到密码 fvcktw123

### 6. docx = zip
- 改后缀 .docx → .zip 解压
- 找隐藏 XML/Image/Binary

### 7. 注释信息
- 压缩包注释位存数据
- 7zip/WinRAR 可见

### 8. 文件修复
- 加文件头: `504B0304` 或 `52617221`
- 修复 CRC
- 010editor 模板自动识别

## 工具
- ARCHPR (Advanced Archive Password Recovery)
- bkcrack (已知明文攻击)
- 010editor (二进制编辑 + 模板)
- WinRAR / 7-Zip
