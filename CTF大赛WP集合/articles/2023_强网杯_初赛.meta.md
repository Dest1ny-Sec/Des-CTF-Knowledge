# 2023 强网杯初赛

## 来源
- 原文：ctfiot.com/152614.html

## 6+ 道题详解

### 强网先锋
1. **Speed up** - 2^27! 各位数求和
   ```python
   from sage.all import *
   aaa = gamma(2^27+1)  # sage 算大阶乘
   bbb = str(aaa)
   res = sum(int(each) for each in bbb)  # 各位数求和
   ```
   - 或查 OEIS 序列

2. **石头剪刀布** - AI 学习模式，固定套路试探
   - 摸黑走迷宫：先错 1 次，根据 Me10n 出法选能赢的出法
   - 脚本：`flag = "000001122012020210211001112220..."`

### crypto
3. **discrete_log** - p-1=2q，bsgs + padding 拆分爆破
   ```python
   # c * pow(g, -padding, p) % p 去填充
   # 12 字节 hex 拆 6+6 走 bsgs, 16^6 * 16^6 = 16^12 但分两表只 16^6
   ```
   - flag 长度 14，但 2^56 太大
   - 12 字节 = 6+6 hex 拆分 bsgs，约 16^7=2 亿次，可接受
   - 实际只需 1000 多万次一发入魂

4. **not only rsa** - n=p^5
   ```python
   n = ... (4096 bit)
   e = 641747
   c = ...
   c = Mod(c, n)
   tmp = c.nth_root(e, all=True)
   for t in tmp:
       if b"flag{" in long_to_bytes(t):
           print(long_to_bytes(t))
   ```
   - sage `nth_root` 自动 lift 模 p^5 的根

5. **babyrsa** - p,q 共享 kbits=100 攻击
   - 复数 RSA: e = inverse(d, (p²-1)(q²-1))
   - 参考虎符 RRSSAA 板子 attack2 LLL
   - 还原 v → pq → p, q

7. **ISIS 论文题** - 2023 美密《Finding short integer solutions when the modulus is small》
   - 论文实现：https://github.com/verdiverdiverdi/ISIS-small-q
   - n=512, m=1024, q=277, nu=1510
   - fpylll BKZ + g6k Siever 联合
   - beta_BKZ/beta_sieve 调大

## 关键技巧
- **sage gamma()**：处理超大阶乘
- **OEIS 序列**：位数和数列直接查
- **bsgs + padding 拆分**：p-1=2q 特殊 DLP
- **nth_root 自动 lift**：模 p^5 一步开根
- **复数 RSA**：自定义 complex_mult + complex_pow
