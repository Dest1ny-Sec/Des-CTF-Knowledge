# 2025 KCTF 第二题《初窥门径》设计思路及解析

## 比赛数据

32 支战队成功提交 flag，前 3 名：
- **时空旅人**：47 分 47 秒
- **COMPASS**：48 分 34 秒
- **山东安在**：1 小时 1 分 36 秒

## KCTF 评委团队点评

> 这道题综合了质因数分解、三维迷宫建模与轻度逆向干扰，设计思路巧妙：
> 通过质数分解恢复迷宫，再利用路径映射字符获取结果，既考察空间建模与图算法，也锻炼选手对函数拆分和 ret 跳转的分析能力，整体兼具趣味性与技术性。
> 但题目在坐标约束上存在疏漏：y 轴仅做 %12 判断，x 轴取模与数据范围不一致，导致实际出现多解。

## 设计思路

出题战队：野鹿子（yegu、mesetop）

```c
#include <stdio.h>
#pragma comment(linker, "/BASE:0x00700000")
const char keydict[] = "0123456789abcdefghijklmnopqrstuvwxyz";
int maze_data[3][9][10] = {
    // 第一层（不可分解为墙，可分解为路）
    {{11278, 4882, 32580, 19499, 2406, 7698, 4707, 6184, 12705, 21166}, ...},
    // 第二层
    {{27900, 15590, 28587, 3969, 20764, 9444, 1925, 23275, 10615, 3067}, ...},
    // 第三层
    ...
};
```

## 解题关键

1. **质因数分解** 还原三维迷宫：不可分解 = 墙，可分解 = 路
2. **路径搜索**（BFS/DFS）在三层 9x10 迷宫中找出口
3. **keydict 36 字符** 映射路径坐标 → 字符 → flag
4. **ret 跳转函数拆分** 轻度逆向干扰，需 IDA 重组函数
5. **y 轴 %12 漏洞** → 多解（评委点名设计疏漏）

## 设计疏漏

- y 轴仅做 `%12` 判断  
- x 轴取模与数据范围不一致  
- 实际出现多解，建议加双重校验 + 最短路径唯一化 + 哈希校验
