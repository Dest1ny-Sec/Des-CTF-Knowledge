# 第十届 CCF 大数据与计算智能大赛 2022 - 大规模金融图数据中异常风险行为模式挖掘 - 冀科数字 二等奖

**赛题**: https://www.datafountain.cn/competitions/586
**团队**: 冀科数字（河北省科学院应用数学研究所 + 天津大学）
**口号**: "做数字时代的勇者"

## 任务
- 简化的金融仿真数据：账户（account/card）+ 边（A2A/A2C）
- 3 阶频繁子图挖掘（频繁度 ≥ 10000）
- 模式：链式子图 + 三角形环路（按欧拉回路构造标准）

## 方案
### 思路
1. 边属性合并编码：`type_tag = source_name + target_name + amt + strategy_name + buscode`
2. 对 type_tag 排序实现边模式快速分类
3. 改"穷举子图"为"先给模式再算频繁度"，省内存
4. 决策树遍历：首边 + 末边（按 type_tag 配对）→ 中间边（按衔接点）

### 算法流程
**Step 1 数据整理**
- 字段格式转换 + 整型化
- 通过 ID 查询补 source_name/target_name
- 合并 type_tag 字段

**Step 2 排序分类**
- 两层排序：type_tag + source_id
- 按 type_tag 标识类别区间，建字典
- 按 source_name+target_name 二次区间标识，建索引字典

**Step 3 计算频繁度**
- 按边属性类别双层循环（首边+末边）
- 由首边终点 + 末边起点查索引字典找可选中间边
- 组合遍历，匹配衔接点 ID，频繁度+1
- 检查阈值，符合则写入结果

## 优化
### 1. 编程语言
- C++ + mmap 加速数据读取
- OpenMP 大循环并行

### 2. 数据处理
- 标签字段整形表达
- 位操作实现属性快速拼接
- 整型数据 O(1) 比较 + O(n log n) 排序

### 3. 遍历剪枝
- 决策树：首边 → 末边 → 中间边
- 概率原则：假设各 ID 出现概率随机
- 子图频繁度估计公式：`E = n_i · n_j · (account_count / total)^3`
- E < 阈值时跳过精确比对

### 4. 衔接点匹配
- 按 source_id 已排序
- 二分查找 O(log n)

## 方案扩展
- 任意模式扩展（标签命名通用化）
- 索引保证结果唯一性
- 支持多种频繁度规则（完全欧拉路径，每边只参与一次）

## 评价
金融风控 + 图计算的工程实践范本。亮点是"边属性标签化 + 排序分类 + 概率剪枝 + OpenMP 并行"4 把刀，将指数级搜索压成线性可处理。30-50% 优化空间声明也说明团队工程严谨。
