# 关于音频隐写的一些总结

## 概览
- **来源**: ctfiot 95105
- **作者**: 天权信安网络安全团队
- **类型**: 音频隐写工具集
- **难度**: ⭐⭐

## 工具集
| 工具 | 用途 |
|------|------|
| Audacity | 频谱图/波形/双声道分析 |
| Adobe Audition (au) | 频谱图精细分析 |
| SilentEye | LSB 隐写 |
| DeepSound | 密码音频隐写 (john 爆破) |
| SSTV | 慢扫描电视 (图片→音频) |
| mp3stego | MP3 隐写 |

## 7 种题型

### 1. WAV (文件头 57415645)
- Audacity 打开: 波形/频谱图
- 上下峰可能暗含二进制/morse
- 倒序反相慢速降噪：单词模糊听写
- 双声道 diff 分离

### 2. SSTV (慢扫描电视)
- 把图片隐藏到音频
- Android: Robot36 APP
- PC: MMSSTV

### 3. DeepSound
- 密码音频隐写
- john 爆破密码

### 4. MP3stego
```bash
# 隐藏
encode.exe -E hidden.txt -P pass CTF.wav svega_stego.mp3
# 提取
decode.exe -X svega_stego.mp3 -P pass
```

### 5. DTMF (拨号隐写)
- 工具: https://gitcode.net/mirrors/ribt/dtmf-decoder

### 6. MIDI (文件头 4D546864)
- 改音乐通道 2→3 找隐藏通道
- 可能藏二维码

### 7. 信号分析 / 原始数据
- HackRF 无线电 / GPS
- PT2242: 4bit 同步 + 20bit 地址 + 4bit 功能 + 1bit 停止
- 后缀 .s8 等奇怪后缀: Import Raw 选采样率/尾端/编码
- 频谱图识别中心频率
