# 2023 极客大挑战 WP

## 概览
齐鲁师范学院网络安全社团主办的极客大挑战 WP，包含 Solidity 多阶段合约 + PIL 图像 XOR 隐写。

## Solidity 三阶段挑战
- **stage1()**: 用 extcodesize 检查调用者是否外部账户，是则加入 isStage1Completed 映射
- **stage2(uint _guess)**: 检查 stage1 完成，生成随机数，要求用户猜对，猜对调 _stage3
- **_stage3()**: 用 extcodesize 判合约账户，调外部 getNumber() 返回两数要求不相等
- **check(address addr)**: 检查特定地址是否已获得标记
- **flag / isStage1Completed**: 状态变量记录完成情况

### 解法
- 部署 attacker 合约，在 constructor 阶段调用 target.stage1() 模拟 EOA（因为 constructor 中 extcodesize 返回 0）
- 然后通过 attacker.foo() 调用 target.stage2(guess)，在合约中算随机数（用 block.prevrandao 或 blockhash）
- 最后调 target._stage3() 满足不相等条件

## 经验提炼
- extcodesize 在合约 constructor 阶段返回 0，这是模拟 EOA 的关键
- Solidity 阶段谜题常见模式：随机数需要合约内生成才能预测
- PIL XOR 二值图解隐写比 RGB 简单，像素值为 0/1
- 阶段谜题需要 attacker 合约串联所有 stage 一次性满足
