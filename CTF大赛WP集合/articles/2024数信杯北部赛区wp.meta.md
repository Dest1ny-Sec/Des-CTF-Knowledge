# 2024 数信杯北部赛区 WP

## 数据安全 Drinktea

`python` 字节码 `dis` 反编译还原源码：32 轮 XTEA 加密，delta=555885348（自定），key=[1900550021, 2483099539, 2205172504, 1359557939]。

加密：
```python
def encrypt(v, key):
    v0, v1 = c_uint32(v[0]).value, c_uint32(v[1]).value
    delta, total = 555885348, 0
    for i in range(32):
        v0 += ((v1<<4 ^ v1>>5) + v1) ^ (total + key[total&3] ^ v1)
        total += delta
        v1 += ((v0<<4 ^ v0>>5) + v0) ^ (total + key[total>>11&3] ^ v0)
    return [v0, v1]
```
解密倒过来跑，4 段密文 [392252415, 2941946969] / [1122976151, 1335193774] / [815478816, 2529100980] / [2237049875, 188954780] → `struct.pack('<I', res1[0])...` 拼出 `acb8739759dc496ccc945703037e037f`。
