# 2023 红明谷杯 5 题 WP

**一、签到**：连点拿 flag（无技术含量）

**二、Dreamer**：梦想家 CMS 后台 → 栏目管理 → 新建顶级栏目 → 封面模版路径 `../../../../../../../../../../flag` → 保存 → 访问前台拿到 flag。

**三、Dreamer_revenge**：同上路径但读 `/proc/1/environ`，或复制 default_v2 主题改 `themePath` 为 `../../../../../../../../../../../../../..` 打包成 default_v3.zip 后台上传启用，模板管理处可读根目录任意文件。

**四、hacker**：分析 PHP 代码：
1. `PDO` 查 zentao 的 `zt_user` 表 → 取 admin 密码（需 SQL 注入或弱口令）
2. `shell_exec($_GET['cmd'])` → 无回显
3. 把 `cmd` 输出 hex 后与密码 hex 循环 XOR，每 62 字符一次 gethostbyname DNS 带外到 `yafgcy.ceye.io`
4. 抓包用密码 `8a3e684c923b763d252cf1e8734a7a29` 还原 XOR 明文
5. 明文是 `api.php data secret.txt` 等文件名 + 一段 `ACCAGTAAAACG{...}`
6. DNA-Cipher 三联密码表替换（A→'a', AAC→'b'...TCA→'1'）→ 还原 UUID flag
7. flag = `flag{d1ee664e-babd-11ed-bb75-00155db0066}`

**五、阿尼亚**：`netpixeljihad.png` 末尾附 hex 数字 → 两次 hex 解码 + Text Encoding BruteForce → 得 zip 密码 → PixelJihad (sekao.net) 解密 → 得 `+-+-++--+-` Decabit code → dcode.fr/decabit-code 翻译。

**六、X 光的秘密**：microDicom 导出无注解灰度图 → Stegsolve 看 LSB → 18/19/20 三张图每字节按位交叉拼接（img1[0][0], img2[0][0], img3[0][0], img1[0][1]...）→ 转回 PNG → 拿到 flag。
