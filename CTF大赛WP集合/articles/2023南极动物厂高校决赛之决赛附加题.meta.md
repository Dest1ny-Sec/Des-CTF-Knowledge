# 2023 南极动物厂高校决赛之决赛附加题

## 来源
- 原文：ctfiot.com/116183.html
- 作者：淡然他徒弟（看雪论坛）
- 比赛：南极动物厂 2023 高校决赛

## 题目分析

### ring3 vs ring0
- ring3 程序 IDA 打开看做了什么
- ring0 程序几乎全部被 tvm0 保护
- 导入表没被保护 → 黑盒分析

### 关键定位
1. ReadProccesMemory 打断点**不蓝屏** → 排除句柄表
2. 0x2023 这个值改掉不蓝屏 → 检测 **Length**
3. Ntoskrnl.i64 → NtReadVirtualMemory → MmCopyVirtualMemory
4. Length 存到临时 MDL 结构

### 跟踪链路
```c
// MmProbeAndLockPages → MmMapLockedPagesSpecifyCache → MmUnlockPages
// MiInsertPteTracker(v8) 中：
typedef struct _PTE_TRACKER {
    LIST_ENTRY ListEntry;
    PMDL Mdl;
    PFN_NUMBER Count;
    PVOID SystemVa;
    PVOID StartVa;
    ULONG Offset;
    ULONG Length;       // ← ByteCount 存这里
    PFN_NUMBER Page;
    ...
} PTE_TRACKER;
```

### 链表入口
- v8 来自 `*MiDeadPteTrackerSListHead` 全局链表
- 触发条件：`MmMapLockedPagesSpecifyCache` 内部当 `MmTrackPtes=1` 时调 `MiInsertPteTracker`

### 赛题驱动做了什么
- 双机调试：硬件断点 `ba w1 fffff8020617318c`（MmTrackPtes 地址）
- 加载 NotepadProtect.sys → 断在驱动里
- 确认赛题驱动置位 `MmTrackPtes=1`

## 绕过思路
1. **绕过**：把 `MmTrackPtes` 置 0，Length 不再插入
2. **复现**：置 `MmTrackPtes=1` + 置 `MiTrackPtesAborted=1`，遍历 `*MiDeadPteTrackerSListHead` 中 Length=0x2023 触发蓝屏
3. 不置 `MiTrackPtesAborted=1` 会立即蓝屏（主动触发）

## 关键技巧
- **tvm0 黑盒分析**：导入表没保护是关键
- **WRK 反推结构**：PTE_TRACKER 结构体定义
- **硬件断点检测**：ba w1 监控标志位写入
- **未导出全局变量**：MiDeadPteTrackerSListHead 在 pdb 中被去除符号

## 适用场景
- Windows 内核逆向
- 反调试与驱动分析
- ReadProcessMemory 检测绕过
- tvm 保护下分析
