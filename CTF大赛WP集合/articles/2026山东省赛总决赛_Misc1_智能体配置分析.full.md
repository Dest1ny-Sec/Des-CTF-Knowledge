# 2026山东省赛总决赛 Misc1-智能体配置分析

## 题目

附件 `transfer.txt`（213 字节），无其他提示。

## 解题

### 1. 识别编码

原始内容是纯 ASCII，没有 PDF/PNG 之类文件头：

```
ewogICJtb2RlbCI6ICJsb2NhbC1jaGF0IiwKICAiZW5kcG9pbnQiOiAiaHR0cDovLzEyNy4wLjAuMTo4MDgwL3YxIiwKICAiYXBpa2V5IjogImZsYWd7YXM2ZGhnZXN4emFvbzR3dXFpamt2dW1uZ2...
```

开头 `ewogIC` 是 base64 里 `{\n  `（大括号 + 换行 + 两空格）的典型特征 —— JSON 缩进格式被 base64 编码后的固定前缀。

### 2. 解码

```bash
base64 -d transfer.txt
```

得到：

```json
{
  "model": "local-chat",
  "endpoint": "http://127.0.0.1:8080/v1",
  "apikey": "flag{as6dhgesxzaoo4wuqijkvumngd6c7a80}",
  "timeout": 60,
  "stream": true
}
```

### 3. 取 flag

`apikey` 字段的值即 flag：

```
flag{as6dhgesxzaoo4wuqijkvumngd6c7a80}
```

## 一句话复现

```bash
base64 -d transfer.txt | python3 -c "import json,sys; print(json.load(sys.stdin)['apikey'])"
```

## 出题视角（为什么这题值得记）

这是典型的 **AI Agent 基础设施配置泄漏**题。真实世界里 agent 的配置文件（OpenAI 兼容 endpoint、api key、模型名）经常被误提交到仓库或打包进镜像。出题人把它 base64 一层，就是在模拟「配置文件进了制品包」的场景。

后续同类题可能变形为：

- 配置藏在 docker-compose / .env / k8s secret 里
- apikey 被分片在多个配置文件中，需拼接
- endpoint 指向内部服务，需要配合 SSRF 才能访问

检测套路：见到无文件头的纯 ASCII 长串，先试 `base64 -d`、`xxd -r -p`、`zlib`，再考虑隐写。
