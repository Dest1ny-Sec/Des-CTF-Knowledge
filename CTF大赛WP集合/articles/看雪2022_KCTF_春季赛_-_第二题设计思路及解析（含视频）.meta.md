# 看雪2022 KCTF 春季赛 | 第二题设计思路及解析（含视频）

**赛事**：看雪2022 KCTF春季赛 Q2《末日邀请》

**难度**：围观3473人，40队破解，一血4h30min（辣鸡战队）

**题目设计**：
- 出题人陪小朋友看奥数时遇到 Collatz 序列觉得有意思
- 加了"砍传奇"回忆杀
- 序列号：`421KCTF381654729`（中间夹KCTF）

**破解步骤**：

**Step 1：CRC32-like折叠生成signA**
```c
v11 = -1;
for (i = 0; i < lenSN; ++i) {
    v11 = arrayA[(unsigned __int8)(v11 ^ Arglist[i])] ^ (v11 >> 8);
}
signA = ~v11;
// signA == 0xF52E0765
```

**Step 2：Collatz序列构造arrayB**
```c
v15 = resultA;
for (j = 1; j < 0xC8; ++j) {
    if (v15 & 1) v15 = 3 * v15 + 1;  // 奇数：3n+1
    else v15 >>= 1;                    // 偶数：n/2
    arrayB[j] = v15;
}
signB = arrayB[0xC6] | arrayB[0xC5] | arrayB[0xC4];
// signB = 1 | 2 | 4 = 7
```

**Step 3：前3字节异或 = signB**
```c
if (signB != (Arglist[2] ^ Arglist[1] ^ Arglist[0]))
// 前3位异或 = 7
```

**Step 4：KCTF固定4字节**
```c
if (Arglist[3] != 0x14)  // '4' - 0x37 = 0x14
if (Arglist[4] != 0xC)   // '2' - 0x37 = 0xC
if (Arglist[5] != 0x1D)  // '1' - 0x37 = 0x1D
if (Arglist[6] != 0xF)   // 'K' - 0x37 = 0xF
```

**序列号**：`421KCTF381654729`
- `421`（前3位异或=7）→ Collatz收敛到1
- `KCTF`（固定）
- `381654729`（8-15位）→ 各位数整除校验

**技术总结**：
- 签到题经典套路：Collatz + 字节异或 + 固定字符串
- 魔改CRC32折叠算法（arrayA查表）
- 0x37偏移还原KCTF字符

**质量评估**：中（结构清晰，flag具体）
