# 2024 数信杯西区题解

## 安全加固

```bash
# SSH
PubkeyAuthentication yes
PasswordAuthentication no
ChallengeResponseAuthentication no
rm -f ~/.ssh/authorized_keys2
service ssh restart

# Apache
ServerTokens Prod
ServerSignature Off
<Directory />
    Options FollowSymLinks
    AllowOverride None
    Require all denied
</Directory>

# Redis
requirepass 6b95fa87
bind 127.0.0.1
redis-server /etc/redis/redis.conf
# flag{FC0F33EF-4599-D30E-F6DF-EE9660A9DAD1}
```

## 应急响应

- `netstat -ano` 发现 121.13.2.33:5432 外链 `flag{121.13.2.33:5432}`
- `ps -aux` 找可疑 `psql`，`cd /proc/PID; ll exe` → `/usr/bin/python3.6` 反弹 shell
- Openfire 改端口：`sed -i 's/9090/12335/g' openfire.xml`

## SQL 盲注二分（log 批量 replay）

```python
import re
def extract_data_from_logs(file_path):
    data = {}
    ascii_pattern = re.compile(r'ascii\(substr\((select\(group_concat\(flag\)\)from\(flag\)\),(\d+),1\)\) > (\d+)')
    response_pattern = re.compile(r'HTTP/1.1" 200 (\d+)')
    with open(file_path) as f: logs = f.readlines()
    for line in logs:
        am = ascii_pattern.search(line); rm = response_pattern.search(line)
        if am and rm:
            pos = int(am.group(1)); v = int(am.group(2))
            data.setdefault(pos, []).append((v, int(rm.group(1)) == 940))
    res = {}
    for pos, vals in data.items():
        vals.sort()
        lo, hi = 0, 127
        for v, ok in vals:
            if ok: lo = max(lo, v+1)
            else: hi = min(hi, v)
        res[pos] = chr(lo)
    return ''.join(res[pos] for pos in sorted(res))
```
940 vs 非 940 长度差判二分。

## 后门清除

