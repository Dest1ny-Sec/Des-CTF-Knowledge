## 题目列表

1道Windows安全:DLL+内核双hook

## 关键考点

### hack.dll(DLL_PROCESS_ATTACH时hook)
```c
typedef BOOL (*Func)(HANDLE, LPVOID, LPCVOID, SIZE_T, SIZE_T*);
Func OriginFunc = NULL;
BYTE HookCode[] = {
    0x48,0xB8,0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00,  // mov rax, [target]
    0xFF,0xE0  // jmp rax
};
BYTE OriginCode[0x50];

void hack() {
    OriginFunc = WriteProcessMemory;
    VirtualProtect(OriginFunc, HookLen, PAGE_EXECUTE_READWRITE, &saved);
    memcpy(OriginCode, OriginFunc, HookLen);  // 备份
    *(__int64*)(HookCode + 2) = (__int64)HackWriteProcessMemory;  // 构造
    memcpy(OriginFunc, HookCode, HookLen);  // hook
    VirtualProtect(OriginFunc, HookLen, saved, &saved);
}

BOOL HackWriteProcessMemory(HANDLE hProcess, LPVOID lpBaseAddress, LPCVOID lpBuffer, SIZE_T nSize, SIZE_T* lpNumberOfBytesWritten) {
    VirtualProtect(OriginFunc, HookLen, PAGE_EXECUTE_READWRITE, &saved);
    memcpy(OriginFunc, OriginCode, HookLen);  // unhook
    printf("Call WriteProcessMemory(%p,%p,%p,%d,%p)", hProcess, lpBaseAddress, lpBuffer, nSize, lpNumberOfBytesWritten);
    GetModuleFileNameEx(hProcess, NULL, FILENAME, MAX_PATH);
    wprintf(L"ProcessName=%s\n", FILENAME);
    BOOL ret = OriginFunc(hProcess, lpBaseAddress, lpBuffer, nSize, lpNumberOfBytesWritten);
    memcpy(OriginFunc, HookCode, HookLen);  // rehook
    VirtualProtect(OriginFunc, HookLen, saved, &saved);
    return ret;
}
```

### DllMain
- DLL_PROCESS_ATTACH:AllocConsole() + freopen("CONOUT$", "w", stdout) + hack()
- DLL_THREAD_ATTACH/DETACH/PROCESS_DETACH:无操作

### 内核驱动部分
- L"\??\xia0ji2333" 符号链接
- IoCreateDevice + IoCreateSymbolicLink
- WPOFFx64:KeRaiseIrqlToDpcLevel + cr0 &= 0xfffffffffffeffff + _disable
- WPONx64:cr0 |= 0x10000 + _enable + KeLowerIrql
- Hook/Unhook:inline hook + jmp rax
- MmCopyMemory函数被hook(内核)

### LDR_DATA_TABLE_ENTRY
- 遍历PsLoadedModuleList获取已加载驱动
- InLoadOrderLinks/InMemoryOrderLinks/InInitializationOrderLinks
- DllBase/EntryPoint/SizeOfImage/FullDllName/BaseDllName

## 实战价值
- DLL_PROCESS_ATTACH + AllocConsole + freopen CONOUT$ 是Windows hook标准模式
- VirtualProtect+12字节inline hook(mov rax+addr+jmp rax)是r3 hook基础
- WPOFFx64(CR0 WP位清零)+inline hook是r0 hook基础
- LDR_DATA_TABLE_ENTRY是Windows驱动遍历标准结构
- re.frida_server是frida检测特征字符串,bypass需要修改源码
