# 【WP】2024年春秋杯夏季赛 "初探勒索病毒" 出题思路详解

## 制作背景
- 2024 上半年全球勒索软件攻击 400+ 起，平均赎金 500 万美元
- 引导了解勒索病毒工作原理、传播方式、应对策略
- 推荐 No More Ransom Project（https://www.nomoreransom.org/zh/decryption-tools.html）

## 题目场景
- 服务器 `banana.jpg` 被 Black Basta 勒索病毒加密
- 还原成功时 `/flag` 可读

## Black Basta 加密原理
- 2023 年 4 月左右的 Black Basta 采用 **ChaCha 密钥流**加密
- 对 64 字节长的文件块执行 XOR 操作
- 加密块位置由文件大小决定
- 默认加密前 5000 字节

## 恢复条件
- 知道 64 个加密字节的明文 = Known Plaintext Attack
- 文件大小 < 5000 字节：无法恢复
- 5000 - 1GB 字节：可完全恢复
- > 1GB 字节：前 5000 字节丢失，其余可恢复
- **必须知道正确位置上的 64 字节明文**（如虚拟机磁盘镜像）

## 解密工具
- SRLabs 发布 Black Basta Buster
- 需 key.block 已知明文块 + xorblocks.py 提取
- 签到题直接提供 key.block

## 攻击命令
```bash
cd /tmp
wget https://github.com/srlabs/black-basta-buster/archive/refs/heads/master.zip -O buster.zip
unzip buster.zip && cd black-basta-buster-master
cp /var/www/html/banana.jpg.sah28vut5 . && cp /var/www/html/key.block .

# 替换项目文件里的错误
sed -i 's/flags/"flags"/' ./decryptblocks.py
export SRL_IGNORE_MAGIC=1
./decryptblocks.py ./banana.jpg.sah28vut5 ./key.block
cp ./banana.jpg.sah28vut5 /var/www/html/banana.jpg
watch cat /flag
./magic.py ./banana.jpg.sah28vut5
# 得到 MAGIC、MAGIC_EXT，然后修改 magic.py
```

## 经验提炼
- Black Basta 用 ChaCha 密钥流加密 64 字节块 + XOR
- 解密需已知 64 字节明文 + 块位置
- SRLabs Black Basta Buster 是开源解密工具
- `SRL_IGNORE_MAGIC=1` 环境变量跳过 magic 检查
- 已知明文攻击 (KPA) 适用于加密算法未变但密钥可推导场景
- No More Ransom Project 是反勒索公益项目
- 文件大小 < 5000 字节加密概率低，可作"全加密"应对
- 文件后缀变化（如 .sah28vut5）是勒索软件特征
- ChaCha 流密码和 Salsa20 同源，state 矩阵结构相同
