# "无痕"驱动的检测与分析

## 概览
Windows 内核 "无痕" 驱动深度分析：从 PE 重映射、CFG 绕劫持系统调用、PoolBigPageTable 检测、PTE 全扫描。

## 1. 重映射方式加载驱动

### 步骤
- 从云端/本地 PE 文件取得加密内层功能驱动资源
- 解密 Shellcode 驱动二进制
- 解析 PE 头 SizeOfImage 字段
- 内核态分配内存
- 手动拉伸 PE，将 Shellcode 放置到分配内存
- 修复重定位表（Reloc）
- 修复导入表（IAT）
- 刷新 SecurityCookie
- 调用 AddressOfEntryPoint 入口点
- **抹除整个 PE 文件头**

### Reloc 修复代码
```c
static VOID RelocateImage(PVOID SourceBase, PVOID MappedBase) {
    const ULONG_PTR LocationDelta = (ULONG_PTR)MappedBase - (ULONG_PTR)SourceBase;
    if (LocationDelta == 0) return;
    auto DosHeader = (PIMAGE_DOS_HEADER)MappedBase;
    auto NtHeaders = (PIMAGE_NT_HEADERS)((PUCHAR)MappedBase + DosHeader->e_lfanew);
    auto OptionalHeader = &NtHeaders->OptionalHeader;
    if (OptionalHeader->DataDirectory[IMAGE_DIRECTORY_ENTRY_BASERELOC].Size == 0) return;
    
    auto RelocationBlock = (PIMAGE_BASE_RELOCATION)((PUCHAR)MappedBase + 
        OptionalHeader->DataDirectory[IMAGE_DIRECTORY_ENTRY_BASERELOC].VirtualAddress);
    auto RelocationEnd = (PIMAGE_BASE_RELOCATION)((PUCHAR)RelocationBlock + 
        OptionalHeader->DataDirectory[IMAGE_DIRECTORY_ENTRY_BASERELOC].Size);
    
    while (RelocationBlock < RelocationEnd && RelocationBlock->SizeOfBlock != 0) {
        const ULONG_PTR EntryCount = (RelocationBlock->SizeOfBlock - sizeof(IMAGE_BASE_RELOCATION)) / sizeof(USHORT);
        PUSHORT RelocationInfo = (PUSHORT)(RelocationBlock + 1);
        for (ULONG_PTR Index = 0; Index < EntryCount; ++Index, ++RelocationInfo) {
            if (!IsDir64Relocation(*RelocationInfo)) continue;
            PUINT_PTR PatchAddress = (PUINT_PTR)((PUCHAR)MappedBase + 
                RelocationBlock->VirtualAddress + ((*RelocationInfo) & 0x0FFF));
            *PatchAddress += LocationDelta;
        }
        RelocationBlock = (PIMAGE_BASE_RELOCATION)((PUCHAR)RelocationBlock + RelocationBlock->SizeOfBlock);
    }
}
```

## 2. 劫持系统调用指针实现通讯

### 攻击路径
```
NtQuerySystemInformation(103, SystemInformation, Length, ReturnLength)
  -> ExpQuerySystemInformation(103, ..., SystemInformation, Length, ReturnLength)
    -> sub_140A0AE40(SystemInformation, Length, &Size)
      -> guard_dispatch_icall_no_overrides(...)
```

### 版本适配
- Win10 19041 ~ Win11 24H2：搜索 `48 8B 05 B9 F6 51 00 85 C9 49 8B CA 41 0F 95 C0 E8 93 1F D0 FF 48 83 C4 38 C3`
- Win11 25H2+：搜索 `48 8B 05 A4 10 53 00 4C 8D 4C 24 44 8B D7 48 8B CB E8 AD 46 CD FF 89 44 24 40 E9 4F 17 00 00`

### HookCallback
```c
__int64 HookCallback(IN __int64 a1, IN __int64 a2, IN __int64 a3, IN __int64 a4) {
    PDRV_COMM_PACKAGE CommPackage = (PDRV_COMM_PACKAGE)a1;
    if (a1 == 0 || a2 != sizeof(DRV_COMM_PACKAGE) || CommPackage->Magic != DRV_COMM_MAGIC) {
        return g_OldCommCallback(a1, a2, a3, a4);
    }
    CommPackage->RetValue = 0x12345678;
    DbgPrint("[+] Magic = 0x%llX CtlCode = 0x%X.\n", CommPackage->Magic, CommPackage->CtlCode);
    return 0;
}
```

### R3/R0 通讯协议
```c
#define DRV_COMM_MAGIC 0x789456123ull

#pragma pack(push, 1)
typedef struct _DRV_COMM_PACKAGE {
    ULONG64 Magic;
    ULONG CtlCode;
    PVOID Buffer;
    ULONG BufferSize;
    ULONG RetValue;
} DRV_COMM_PACKAGE, *PDRV_COMM_PACKAGE;
#pragma pack(pop)
```

## 3. 检测 PoolBigPageTable 内存痕迹（Win11 25H2）

### MmAllocateContiguousMemory 路径
```
MmAllocateContiguousMemory(NumberOfBytes, HighestAcceptableAddress)
  -> MiAllocateContiguousMemory(a1 = &NumberOfBytes, ..., a3 = HighestAcceptableAddress >> 12, ...)
    -> v17 = ((*a1 >> 12) + ((*a1 & 0xFFF) != 0))  // 实际分配页数
    -> MiMapContiguousMemory(..., v17 << 12, ...) = Va
      -> ExInsertPoolTag(..., Va, v17 << 12)
        -> ExpAddTagForBigPages(a1 = Va, ..., a3 = ALIGN_UP(v17 << 12, 0x1000))
          -> PoolBigPageTable[slot].Va = a1
             PoolBigPageTable[slot].Size = a3
```

### POOL_BIG_PAGE_INFO 结构
```c
typedef struct _POOL_BIG_PAGE_INFO {
    volatile ULONG_PTR Va;        // +0x00
    UCHAR Reserved0[8];           // +0x08
    SIZE_T NumberOfBytes;         // +0x10
    UCHAR Reserved1[8];           // +0x18
} POOL_BIG_PAGE_INFO;
```

### 检测方法
1. 扫一遍 PoolBigPageTable
2. 加载靶场驱动
3. 再扫一遍
4. 新增条目 = 驱动所在内存

## 4. 扫描内核态所有可执行内存

### PTE 4 级页表遍历
```c
ULONG64 Cr3 = __readcr3();
ULONG64 Pml4Pa = Cr3 & (~0xFFF);
// PML4 -> PDPT -> PD -> PT
// 512 × 512 × 512 × 512 页面
// 跳过 NoExecute 位为 1 的页
// LargePage 1GB / 2MB
```

### PAGE_ENTRY_64 结构
- Present (1) / Write (1) / User (1) / WriteThrough / CacheDisable / Accessed / Dirty
- LargePage (1) / Global (1) / CopyOnWrite / Prototype / Reserved0
- PageFrameNumber (36) / Reserved1 (4) / SoftwareWsIndex (11) / NoExecute (1)

## 经验提炼
- PE 重映射需修复 Reloc/IAT/SecurityCookie 三件套
- 劫持 NtQuerySystemInformation 间接 call 走 CFG guard_dispatch_icall
- PoolBigPageTable 记录大块连续内存分配
- PTE 4 级页表遍历扫描可执行页是反 rootkit 利器
- `_InterlockedCompareExchangePointer` 原子替换回调指针
- `DRV_COMM_MAGIC` 协议头是 R0/R3 通讯标识
- 抹除 PE 头是反取证常用手法
- InterlockedCompareExchangePointer 替换 g_OldCommCallback 寻址后修复重映射基址
