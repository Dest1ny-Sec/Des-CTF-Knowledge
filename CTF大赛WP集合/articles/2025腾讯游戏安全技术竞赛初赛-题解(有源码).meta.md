# 2025 腾讯游戏安全技术竞赛 - 初赛 (有源码)

## 速读
作者 dejavusecure — R3+R0 双层反调试 + 自定义 base58 + 驱动通信。

## 反调试绕道
```
eb 模块地址+10D0  C3
// ret 用于阻止 R3 反调试执行
eb 模块地址+1370  48 C7 C0 01 00 00 00 C3
// mov rax, 1; ret 用于阻止 R0 驱动加载
```

## 加密流程
1. R3 校验: 头部必须为 `ACE_`
2. 释放 base58 自定义字符集
3. 释放异或密钥 `sxx`
4. base58_encrypt → 倒序 → 头加 '@'
5. XOR `sxx` 循环
6. `ACEDriverSDK::Communicate(+96)` 经 `FilterSendMessage` 传到 R0 驱动
7. R0 驱动做最终密文校验
