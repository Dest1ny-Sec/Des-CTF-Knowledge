# 春秋杯Re 2024 赛题解析

**赛事**：春秋杯2024逆向（看雪论坛螺丝兔）

**三题详解**：

**1. Snake（pygame Python逆向）**
- 简单RC4+循环次数异或
- 思路：CE改9999分数需暂停游戏；IDA调试挂起进程不易
- 在线反编译pyc即可看出算法

**2. HardSignin（UPX壳+TLS+TEA）**
- 改了所有UPX字样为VMP迷惑 → 改回即可用工具脱UPX4.24壳
- ESP断点失效（手脱失败原因）
- TLS_3回调函数生成base64/RC4/TEA码表和密钥
- 4个TLS：1个异或main函数代码 + 3个反调试
- IDC脚本patch main函数：
  ```c
  static main() {
      auto x, Fbin, ProcRange;
      for (x=0x401890; x<0x40193A; x=x+1) {
          Fbin = Byte(x);
          PatchByte(x, Fbin^0x66);  // nop掉
      }
  }
  ```
- 算法：`base64 + RC4 + TEA`
- TEA delta=0x61C88647（标准），rounds=100
- Key: `0x0CAA5BDD, 0xD6846924, 0x51041EB8, 0x8B2AAB06`

**3. Bedtea（Nim语言）**
- 时间反调试（两次取时间比较） → 把if改成恒跳转
- 调试=1，非调试=3 → 该值经斐波那契数列生成TEA密钥
- 二叉树：先序遍历创建 + 后序遍历 = 输入倒序
- 0x33异或每字符
- TEA delta=0x61CBB648（非常用变种），sum从0x987E55D0开始
- 多组密钥分段解密：
  - k={0x3,0x5,0x8,0xD}
  - k1={0x15,0x22,0x37,0x59}
  - k2={0x90,0xE9,0x179,0x262}
- **flag{y0u_reallyl1ke_te@}**

**技术要点**：
- UPX改字样迷惑 → 改回即可
- IDC PatchByte批量patch
- TLS回调生成密钥
- Nim语言反编译特征
- TEA delta变种：0x9E3779B9(标准) / 0x61C88647(等价) / 0x61CBB648(变种)

**质量评估**：高（命令级解密脚本 + flag）
