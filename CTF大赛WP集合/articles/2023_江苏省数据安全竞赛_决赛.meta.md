## 8+ 道题详解

### crypto-easy_rsa
- 基础 RSA，e 和 phi 公因子 5
- `d = inverse(e/5, phi)`，`m = pow(c, d, n)`，`m = iroot(m, 5)[0]`
- 与密文 XOR 还原 flag
- flag: `flag{dyfohoday36826cg0a531rc9cg8yw4c2xl08}`

## 哥斯拉加密还原
```python
import gzip
def dec(c, key):
    p = ""
    for i in range(len(c)):
        p += chr(ord(c[i]) ^ ord(key[(i+1) & 15]))
    return p

# base64 + XOR + gzip → 明文
gg = dec(b64decode(cipher).decode("latin1"), "6cfcfe9b99c68a0a")
print(gzip.decompress(gg.encode("latin1")).decode())
```

## 关键技巧
- **哥斯拉协议**：XOR(16 byte key) + base64 + gzip
- **AES key 爆破**：md5(hex 5 字符) 遍历 0x100000，找 PKCS#7 padding 校验
- **内存取证**：volatility netscan + pslist + memdump 组合
- **ThinkPHP 版本**：composer.json 包含版本号
