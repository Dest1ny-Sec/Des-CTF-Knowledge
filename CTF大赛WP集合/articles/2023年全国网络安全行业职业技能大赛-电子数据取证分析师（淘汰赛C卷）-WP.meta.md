# 2023 年全国网络安全行业职业技能大赛 - 电子数据取证分析师（淘汰赛 C 卷）- WP

## 来源
- 原文：ctfiot.com/155630.html
- 公众号：取证与溯源

## 5 检材 20 题

### 检材 1（手机备份）
- 1. 文件类型：ext4
- 2. 系统版本：5.1
- 3. 时区：Asia/Shanghai
- 4. IMEI 号
- 5. hlnet WiFi 密码：HL1sbetter

### 检材 2（E01 镜像）
- 1. SHA-1 值
- 2. index.rar 文件 SHA-1

### 检材 3（远程取证）
- 1. 最近一次远程登录 IP
- 2. 最近一次服务器关机时间
- 3. 网站路径
- 4. 数据库配置文件路径

### 检材 4（监控镜像）
- 1. 监控厂商名
- 2. 硬盘格式化时间
- 3. 起始扇区
- 4. 数据块大小

### 检材 5（虚拟磁盘）
- 1. 系统版本号
- 2. 命令历史第 11 条
- 3. 第一次登录 IP
- 4. 宝塔面板默认账号密码
- 5. 虚拟货币诈骗网站源码路径
- 6. 宝塔面板联系人手机号

## 关键技巧
- **ext4 文件系统识别**：检材头部 magic
- **E01 镜像 SHA-1**：直接计算整文件
- **监控厂商识别**：字符串匹配
- **格式化时间**：文件系统 metadata 时间戳
- **宝塔面板**：/www/server/panel/config.json

- 手机取证
