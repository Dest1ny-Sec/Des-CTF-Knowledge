# 2024 网鼎杯 半决赛 & 决赛

## 半决赛

### RSA（已知 p 高 256 bit）

```python
# 已知：n, e=0x10001, p 高 256 bit
p_high = 0xe700568ff506bd5892af92592125e06cbe9bd45dfeafe931a333c13463023d4f0000...

R.<x> = Zmod(n)[]
f = (p_high >> 8) + x   # 已知 p 高 248 bit
f.small_roots(X=2^248, beta=0.49, epsilon=0.014)  # Coppersmith
```

爆破剩余 7 bit（38 分钟/单进程 sagemath）→ 完整 p。

### 序列密码（LFSR + NFSR + NOISE）

```python
nbit = 128
class LFSR:
    def __init__(self, seed, mask):
        self.state = seed & (2**nbit-1)
        self.mask = mask & (2**nbit-1)
    def __next__(self):
        b = (self.state & self.mask).bit_count() & 1
        self.state = ((self.state << 1) | b) & (2**nbit-1)
        return b

class NFSR:
    def __init__(self, lfsr0, lfsr1, noise):
        self.lfsr0, self.lfsr1, self.noise = lfsr0, lfsr1, noise
    def __next__(self):
        return self.lfsr0(1) ^ self.lfsr1(1) ^ next(self.noise)

def NOISE(lfsr, p=2/3, prec=256):
    while True:
        if lfsr(1): yield int(secrets.randbelow(2**prec) / 2**prec > p)
        else:       yield int(secrets.randbelow(2**prec) / 2**prec <= p)
```

**核心洞察**：
- 两个 128 bit LFSR 每局重置
- 12 bit LFSR 控制 noise（seed/mask 各 12 bit）
- 512 次请求 × 128 字节密文
- noise 期望 = (1+2)/2/3 = 0.5 但带偏置：
  - lfsrn=1 → noise 是 1 概率 1/3
  - lfsrn=0 → noise 是 1 概率 2/3
- 多次采样求 noise 期望 → 反推 lfsrn 状态

**关键 bug**：`solve right` 和 `solve left` 搞反，1/4 概率恢复 seeds。

**思路**：
1. 求 φ1 的逆映射 φ1^(-1) 和 φ2 的逆映射 φ2^(-1)
2. `m(φ1(x)) = C - 2*φ1(x)*r(φ1(x)) (mod F1(x))` → `m' = C - 2*φ1(x)*r(φ1(x))`
3. `m' = m(φ1(x))` → `m = m'(φ1^(-1)(x))`（用 phi1^(-1) 替换 x）
4. 提取 m 的系数 (二元域上) → 还原 128 bit key
5. AES-ECB 解密 cipher
