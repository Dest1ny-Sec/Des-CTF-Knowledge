# 2025 騰訊遊戲安全大賽 (安卓決賽)

## 速读
作者 ngiokweng — UE4 安卓反作弊全套检测技术详解。

## cheat 设备检测
```c
for(int i = 9; i < 256; i++) {
    sprintf(buf, "/sys/devices/virtual/input/input%d", i);
    lstat(buf, &st);
    // 特征 1: mtime == atime == ctime
    if (st_mtim == st_atim && st_atim == st_ctim) {
        // 特征 2: 时间窗口 ≤ 0x10
        if (now <= st_mtim || (now - st_mtim) <= 0x10) {
            // cheat device!
        }
    }
}
```

## 函数完整性
```c
// sub_6711A54 原始 CRC32 = 0x49d5c836
uLong crc_val = crc32(0, base+0x6711A54, 0x224);
return crc_val != 0x49d5c836;  // 被 patch 则返回 true
```

## 三重内存检测
- **mprotect**: 监控 PROT_READ|WRITE|EXEC 切换
- **inotify**: 监控 .so/.py 文件加载
- **mincore**: 检测地址是否在物理内存

## 假内存注入
```c
// libUE4.so +0xAF75B08 注入
fake_memory = mmap(0, pagesize, RWX, MAP_ANON|MAP_SHARED, 0, 0);
memcpy(fake_memory, original_arr, arr_len*24);
// 末尾加一个 never_access_address
*(fake_memory + arr_len*24) = never_access_address;
```
