## Frida Hook EXP
```python
import frida, glob, time
target = glob.glob("【2026春节】解题领红包之十*Windows 高级题*出题老师：Poner.exe")[0]
js = r'''
const base = Process.enumerateModules()[0].base;
const f_cd490 = new NativeFunction(base.add(0xCD490), 'uint64', ['pointer','pointer']);
const g_b418 = base.add(0x2632418);
const g_b419 = base.add(0x2632419);
let lastY = '';
function toHex(ptr, n){
    const u = new Uint8Array(ptr.readByteArray(n));
    return Array.from(u).map(x => x.toString(16).padStart(2, '0')).join('');
}
Interceptor.attach(base.add(0xD3B20), {
    onEnter(args) { lastY = toHex(args[1], 64); }
});
Interceptor.attach(base.add(0x0C1B90), { onLeave(ret) { ret.replace(ptr(0)); } });
Interceptor.attach(base.add(0x09B30), { onLeave(ret) { ret.replace(ptr(0)); } });
rpc.exports = {
    derive(uid) {
        g_b418.writeU8(0); g_b419.writeU8(0); lastY = '';
        f_cd490(Memory.allocUtf16String(uid), Memory.allocUtf16String('00'.repeat(64)));
        return lastY;
    },
    verify(uid, flag) {
        g_b418.writeU8(0); g_b419.writeU8(0);
        return f_cd490(Memory.allocUtf16String(uid), Memory.allocUtf16String(flag)).toString();
    }
};
'''
pid = frida.spawn([target])
session = frida.attach(pid)
script = session.create_script(js)
script.load()
frida.resume(pid)
api = script.exports_sync
flag = api.derive("uid")
ret = api.verify("uid", flag)
```

## Windows RE 标准流程
1. 64 字节目标缓冲生成
2. sub_1400CF270 长度校验 = 0x40 字节 (128 hex 字符)
3. sub_1400CF910 核心调度 (含反调试)
4. sub_1400D3B20 最终 64 字节比较
5. mov r8d, 40h + call sub_1400D3B20

## 复核链路
- ctf_request 填口令本身 (不是 access_token)
- audit_log_id 用被拒访问完整编号 (不截断不改)
- 同一会话最近拒绝出来的编号, 跨会话/旧编号不行
- 复核凭据有时效, 失败后重新触发拒绝拿新编号
- 复核阶段凭据只打通流程, 最终读密卷还需后续凭据

## 教学
- Native 验签成功判定: h1.a.S((byte[]) obj) == null
- WASM 0x2026 = 8230 次 SHA-256 是反调试 (慢)
- Frida hook 0xD3B20 onEnter 拿 64 字节目标
- hook 反调试清零函数 0x0C1B90 / 0x09B30
