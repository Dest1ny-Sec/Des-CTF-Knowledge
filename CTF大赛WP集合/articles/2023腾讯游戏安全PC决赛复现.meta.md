# 2023 腾讯游戏安全 PC 决赛复现

**一、外挂进程查杀**

```cpp
bool KillProcessByName(const char* processName) {
  HANDLE hSnapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
  PROCESSENTRY32 pe = { sizeof(pe) };
  if (Process32First(hSnapshot, &pe)) do {
    if (strcmp(pe.szExeFile, processName) == 0) {
      HANDLE hProcess = OpenProcess(PROCESS_ALL_ACCESS, FALSE, pe.th32ProcessID);
      if (hProcess) { TerminateProcess(hProcess, 0); CloseHandle(hProcess); Num++; }
    }
  } while (Process32Next(hSnapshot, &pe));
}
```

主循环 while(1) 调 `KillProcessByName("WorkingService.exe")` 持续查杀外挂进程。

**二、DLL 注入 + Detours Hook**

```cpp
BOOL InjectDll(HANDLE hProcess, LPCSTR dllPath) {
  LPVOID pRemoteDllPath = VirtualAllocEx(hProcess, NULL, strlen(dllPath)+1,
                                          MEM_COMMIT, PAGE_READWRITE);
  WriteProcessMemory(hProcess, pRemoteDllPath, dllPath, strlen(dllPath)+1, NULL);
  LPTHREAD_START_ROUTINE lpLoadLibrary = (LPTHREAD_START_ROUTINE)
      GetProcAddress(GetModuleHandleA("kernel32.dll"), "LoadLibraryA");
  HANDLE hThread = CreateRemoteThread(hProcess, NULL, 0,
                                       lpLoadLibrary, pRemoteDllPath, 0, NULL);
  WaitForSingleObject(hThread, INFINITE);
  // ...
}
```

注入前先 `RemoveHook` 还原 ntdll+0xA0990 处的 NtProtectVirtualMemory 24 字节 syscall stub 原貌，绕开外挂对 ntdll 的 hook。

**三、HookedCreateFileA + TLS 计数**

```cpp
tlsIndex = TlsAlloc();
TrueCreateFileA = (CreateFileA_t)DetourFindFunction("kernelbase.dll", "CreateFileA");
DetourAttach(&(PVOID&)TrueCreateFileA, HookCreateFileA);

HANDLE WINAPI HookCreateFileA(...) {
  LPVOID tlsValue = TlsGetValue(tlsIndex);
  if ((DWORD_PTR)tlsValue <= 0x10) {
    TlsSetValue(tlsIndex, (LPVOID)((DWORD_PTR)tlsValue + 1));
  } else {
    static int Num = 0;
    if (++Num == 16) exit(0);
    ExitThread(0);
  }
  return TrueCreateFileA(...);
}
```

每线程最多允许 16 次 CreateFileA，超过就自杀线程，16 线程都死就 exit 整个进程让守护进程重启。`#pragma comment(lib,"detours.lib")` 编译期绑定 Detours 库。

**关键点**：jmpBytes 5 字节长跳（0xE9 + 32 位相对偏移）+ originBytes 是 ntdll NtProtectVirtualMemory 原 24 字节 syscall 入口（4C 8B D1 B8 50...0F 05 C3 CD 2E C3）。
