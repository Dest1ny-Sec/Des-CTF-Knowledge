# 解析 2025 强网拟态 FMS - LCG PRNG 状态恢复攻击

**来源**: ctfiot.com ID 277011

## 题目概述
- Flag 管理系统 main.py
- 功能: [L]ogin / [G]et Public Key / [R]ead Flag / [E]xit
- 后门: Get Public Key 直接泄露完整 LCG 参数 a, b, p

## LCG 数学
```python
state_{n+1} = (a × state_n + b) mod p
```
- p 是 128 位素数
- admin 密码由 PRNG 生成的 32 个随机字符组成
- 每次 randbytes 输出 PRNG 状态低 8 位
- 登录失败不影响 PRNG 状态继续前进

## 攻击链

### Step 1: 获取 LCG 参数
调 Get Public Key → 拿到 a, b, p

### Step 2: 收集低 8 位样本
多次失败登录（不影响 PRNG），每次收集 1 字节输出：
```python
T_i = state_i mod 256  (i = 1, 2, ..., 128)
```

### Step 3: LLL 格基规约恢复种子 s

构造格基矩阵：
- 每个 T_i 对应一个方程
- 状态演化: state_i = a^i × s + b × Σ_{j=0}^{i-1} a^j mod p
- T_i = state_i mod 256

变量: s, h_1, ..., h_128 (h_i = state_i 的高位)
方程: state_i - 256 × h_i = T_i
约束: 0 ≤ h_i < 2^120

LLL 找短向量 = 满足所有约束 + 在范围内的解 = 正确 s

### Step 4: 复现 admin 密码
```python
state = s
for i in range(32):
    char = state & 0xFF  # 模拟 randbytes
    admin_pwd += chr(...)
    state = (a * state + b) % p
```

### Step 5: 登录 + 读 flag
- Login: admin + 复现的密码
- Read Flag → 加密 flag

## 关键技术
- LLL 格基规约（短向量问题 SVP）
- Hidden Number Problem (HNP)
- Fermat 小定理: a^(-1) ≡ a^(p-2) mod p
- 模运算 + 模逆
- 截断 LCG 攻击（低 8 位比高 8 位弱）

## 128 个样本足够
- 信息论: 128 字节 = 1024 bit 约束
- 128 位种子 = 128 bit 未知数
- 约束 ≥ 未知数 → 唯一解

2025 强网拟态 LCG 密码学高质量题。考察 LCG 弱随机性 + 格基规约（LLL）实战。Get Public Key 后门设计巧妙，考察选手对密码学 PRNG 攻击的系统理解。
