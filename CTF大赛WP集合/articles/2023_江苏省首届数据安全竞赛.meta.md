## crypto-easy_rsa 详解

### day() 函数
```python
def day():
    A = [getRandomRange(1 << 30, 1 << 40) for _ in '01234']  # 5 个 30-40 bit 数
    hint = str(A)[1:-1].replace(', ', '||').encode()  # 拼字符串
    hint2 = bytes_to_long(pad(hint))  # pad 2048 bit（高位填 0）
    package = []
    for pubkey in pubkeys:  # 5 个 e=13 公钥
        e, n = pubkey
        package.append(pow(hint2, e, n))
    return A
```

### night() 函数
```python
def night(A):
    p, q = [getPrime(1024) for _ in '01']
    e, n = 0x10001, p * q
    ciphertext = pow(bytes_to_long(pad(secret)), e, n)
    core = getRandomRange(1 << 70, 1 << 80)  # 80 bit 随机
    box = (A[4] * p**4 + A[3] * p**3 + A[2] * p**2 + A[1] * p + core) % n
    shell = (A[4] * box**4 + A[3] * box**3 + A[2] * box**2 + A[1] * box + A[0]) % n
```

### 攻击思路

#### 1. RSA 低指数广播攻击
- 5 个 e=13 公钥，hint 约 560 bit
- pad 是高位填 0：`hint2 = hint1 * pad`（pad 已知）
- 改密文：`c_i' = c_i * pow(pad, -13, n_i) % n_i`
- CRT 合并：hint1 = crt(c_i', n_i) ** (1/13)

#### 2. Coppersmith 分解模数
- 从 `shell` 方程：A[4]*box^4 + A[3]*box^3 + A[2]*box^2 + A[1]*box + A[0] = shell (mod n)
- 在 mod p 下：`A[4]*box^4 + A[3]*box^3 + A[2]*box^2 + A[1]*box + A[0] = shell (mod p)`
- 把 shell 看作 A[0] 的关系式，mod p 下解小根（A[0] 是 30-40 bit 已知量）
- Coppersmith 攻击还原 p

#### 3. 标准 RSA 解密
- p 已知后 q = n // p
- d = inverse(e, phi)
- m = pow(ciphertext, d, n)

## 关键技巧
- **pad 高位已知**：hint2 = hint1 * pad → 改密文消去 pad
- **CRT 广播攻击**：e=13 需要 13 个公钥，这里 5 个 + pad 调整可行
- **Coppersmith**：小根（30-80 bit）+ 模 p 多项式 → 还原 p
- **多项式分解**：A[i] 系数全部已知，shell 是 box 的多项式

## 适用场景
- RSA 低指数广播攻击变种
- 模 p 多项式 + Coppersmith
- 5 个 pubkey 共享 hint 加密
- 多步骤 RSA 攻击链
