flag: openssldgst-sha256/opt/document.txt

### Q2-Q4: openssl RSA
```bash
# 解密
openssl rsautl -decrypt -in secret.enc -inkey private_key.pem -out flag.txt
flag: flag{you_re_very_good_at_crypto}
# 公钥
openssl rsa -in private_key.pem -out public_key.pem -pubout
flag: opensslrsa-inprivate_key.pem-outpublic_key.pem-pubout
# 验证
openssl dgst -sha1 -verify public_key.pem -signature document.sha256 document.txt
flag: verificationfailure
```
