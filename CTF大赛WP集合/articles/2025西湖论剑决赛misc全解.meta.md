# 2025 西湖论剑决赛 misc 全解

## 速读
多链路取证题 — 4 个独立小链组合。

## 链 1: 文件名拼 zip
```python
folders.sort(key=os.path.getmtime)
zipp = "".join(os.path.basename(folder)[0] for folder in folders)
zip_data = binascii.unhexlify(zipp)
```

## 链 2: 冰蝎 4 + 冰蝎 3
- 解冰蝎 4 流量得 XOR 密钥
- 用密钥解冰蝎 4 流量 → 得到 she1l.php 冰蝎 3 脚本
- 批量解冰蝎 3: `AES-CBC(iv=16*0x00, key="5b4582c9d56b5b33")` + base64

## 链 3: 拼图
- 解密 + 二次 base64 → PNG 切片
- 拼成 Steganography_challenges0.3.png

## 链 4: RC4 像素级
- key = "password"
- PIL 逐像素 RGB → RC4 decrypt → 新像素
