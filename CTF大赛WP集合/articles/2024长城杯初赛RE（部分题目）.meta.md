# 2024 长城杯初赛 RE easyre

## 加密逻辑

```c
input = argv[1];
j = 1;
for (i = 0; i != 43; ++i) {
    input->m128i_i8[i] ^= input->m128i_u8[i + 1 + -42 * (j / 42)];
    ++j;
}
```

简化：
```c
for (int i = 0; i < 43; ++i) {
    input[i] ^= input[i + 1 - 42 * (i + 1 / 42)];
}
```

- 前 41 位：`input[i] ^= input[i+1]`（前位 xor 后一位）  
- i=41: `input[41] ^= input[0]`（环回）  
- i=42: `input[42] ^= input[1]`

## SSE 校验

```c
if (_mm_movemask_epi8(
    _mm_and_si128(
        _mm_cmpeq_epi8(_mm_loadu_si128(input), data1),
        _mm_cmpeq_epi8(_mm_loadu_si128(input + 1), data2)
    )
) == 0xFFFF)
```

`_mm_loadu_si128(input)` 加载 16 字节，`_mm_cmpeq_epi8` 字节级比较，全相等 = 全 0xFF。  
`_mm_movemask_epi8` 取每个字节最高位形成 16-bit 整数，== 0xFFFF = 16 字节全相等。
