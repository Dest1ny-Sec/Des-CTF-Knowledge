# 2024 能源网络安全大赛预赛【金盾检测】

## 1. gooooose-A（GOOSE 协议异常数据）

```bash
tshark.exe -r data.pcapng -e "goose.integer" -T fields
```

提取 GOOSE 报文的 4 个 item，第 4 个小于 128 的数转 ASCII：

```python
data = '''1804289383,846930886
1714636915,1957747793
...
756898537,1734575198,84
...'''.split('\n')
flag = ""
for each in data:
    if each == "": continue
    tmp = each.split(",")
    s = tmp[-1]
    if int(s) < 128:
        flag += chr(int(s))
print(flag)
# TVpXR0NaMzNNTlJHS05KVEc0NERNTUpVTU1ZREdOWlRHSjZRPT09PQ==
```

base64 → base32 → flag 文本。

## 6. seeyouagain-A（base64 隐写）

```python
table = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"
for each in data:
    if each == "": continue
    cipher = each
    num = cipher.count("=")
    if num == 0: continue
    cipher = cipher[:-num]
    sbin = ""
    for i in cipher:
        sbin += bin(table.index(i))[2:].rjust(8, '0')
    hidebit = sbin[-num*2:]  # 末尾 num*2 bit 隐藏
    flag += hidebit
```

二进制串 → 转 ASCII。
