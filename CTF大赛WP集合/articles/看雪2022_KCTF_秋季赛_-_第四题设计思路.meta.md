# 看雪2022 KCTF 秋季赛 | 第四题设计思路

**赛事**：看雪2022 KCTF秋季赛 Q4《治水搁浅》

**难度**：攻破数为0（无人提交）

**题目设计**：
- 矩阵C由未知向量a生成
- check函数取RSA加密后的前1920比特
- check函数取RSA加密后的后1920比特
- 验证表达式成立

**破解思路**：

**Step 1：求私钥x**
- 已知矩阵C + 关系式(4) → 解方程求a
- 代回(4)式求私钥x

**Step 2：恢复前1920比特**
- **若求出的x的比特数 < 1920**：
  - 实际是因为check函数中取前1920比特转化为整数后的值大于p
  - 真正的前1920比特 = x + i*q
  - 本题中i值很小（1=3）→ **穷举i恢复真前1920比特**

**Step 3：拼接后1920比特**
- check函数取RSA加密后的后1920比特
- 前后1920比特各恢复后，拼接成3840比特的数

**Step 4：RSA-3840解密**
- 私钥已知 → 解密
- 3840 bit = 480 byte
- 用户输入按序列号格式转化

**flag**：

**关键技术**：
- 矩阵C求a（线性方程组）
- 比特数<1920时加iq穷举（i小可穷举）
- LLL/sage实现
- 3840比特RSA大数解密

**质量评估**：高（虽然无人攻破，但设计思路+ flag完整）
