# 2023 N1CTF

## 来源
- 原文：ctfiot.com/164382.html
- 比赛：N1CTF 2023

## 题目详解

### 1. e2W@rmup（ECDSA nonce 拼接泄漏 + LLL）
- nonce = msg_hash[0:128] + d[0:128]（前 128 + 后 128 拼接）
- 拆 d = (dh << 128) + dl，知道 dh 高位 + dl 完整
- 由 ECDSA 公式 `s = k^(-1) * (msg_hash + r*d)` 推
- 构造格：
  ```
  L = Matrix(ZZ, [[R*(2^128*r - s), 1, 0],
                  [R*(M*s - msg_hash), 0, 2^128],
                  [order, 0, 0]])
  L = L.LLL()
  ```
- 加 bruce1/bruce2 = 0b11<<126 缩小搜索空间
- `small_roots(f, bounds, m=3, d=4)` 恢复完整 d
- `long_to_bytes(d)` 当 AES-ECB key 解密 cipher

### 2. e20k（ECPrng pqr 三素数分解）
- ECPrng 状态在 `E: y^2=x^3+7 mod N`，N=pqr 三素数
- `keygen`: P=256-bit prime, q=256-bit prime, is_prime(2q-1) → Q=2q^2-q, N=P*Q
- 用 Williams p+1 + 二次剩余分解 N
- 关键：EN_random_element_k k=3 用 CRT 拼 (Ep, Eq, Er) 三素数域上的 EC 点
- 把 state 设为 3-torsion 元素，下次 state = 4*state = state（不动点）
- 拿到 x,y 当 prng seed，跑后续 PRNG 逻辑恢复 secret

### 3. RSA Coppersmith（mask 加密）
- flag 拆字节 `m = m XOR mask`，`c = pow(0x10001, m, key)`
- mask 较小，用 Coppersmith 攻击爆破低比特位

## 关键技巧
- **ECDSA 拼接 nonce**：nonce = msg|key 拼接时 d 可拆为高位低位联合爆破
- **LLL + small_roots**：高维格联合 Coppersmith 是恢复拼接私钥的标配
- **pqr 三素数分解**：N=P*Q 当 P,Q 有特殊结构（2q-1 prime）时可分解
- **CRT EC 点拼装**：3 个素数域 EC 点用 CRT 拼 N 上 EC 点（k-torsion 技巧）
- **Coppersmith on RSA mask**：低 bit 已知是标准攻击
