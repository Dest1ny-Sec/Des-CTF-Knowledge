# 网鼎杯 2024 白虎/crypto001

**自定义 S 函数 + 等效 key 转换 + 线性方程组还原**

> 网鼎杯 · 2024 · medium · crypto_unknown/block_cipher · quality=medium
> 思路: 识别 S 函数结构：IV=7, block_size=64, MASK=64bit → 简化 S：x2 ^ x3 = x0 ^ MASK（其中 x0 = x<<IV & ((1<<block_size)-1)） → 推出 enc(x) = S(x) ^ key = x ^ x0 ^ MASK ^ key → 等效 key 理论：S 复合轮函数可用等效 key 替换 → 解密：先异或 MASK 泄低位，再 unshiftLeft 恢复高位（MT19937 风格） → 备选 kkp 脚本：enc(x, key^key2^key3) = enc(x, key1) ^ enc(x, key2) ^ enc(x, key3) → 用线性方程组求 key，再求 msg
> 套路: 自定义分组密码的 S 函数可通过等价 key 替换和线性方程组分析还原；MASK 异或泄低位 + unshiftLeft 恢复高位是 MT19937 类还原通用思路

**关键 payload**:
```python
def S(x):
    x1 = x
    x2 = x << IV & MASK
    x3 = x << IV & ((1 << block_size) - 1) | MASK
    return x1 ^ x2 ^ x3
```
