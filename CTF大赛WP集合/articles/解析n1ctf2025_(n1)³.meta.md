# 解析 n1ctf 2025 (n1)³ - 张量分解攻击

**来源**: ctfiot.com ID 278359
**考点**: 张量分解 / Jennrich 算法 / 有限域 / 三次多项式

## 题目信息
- `task.sage` 加密脚本
- `output.txt` 加密输出
- 工作在 GF(257) 上（257 是质数）
- FLAG 编码：`ZZ.from_bytes(FLAG).digits(257)`，35 维
- 加密函数：`enc(x) = (x * U).apply_map(lambda c: c^3) * T`
- U, T 是 35×35 随机可逆矩阵

## 数学结构
f(x) = ((xU)^{[3]}) T = Σ_(k=1 to 35) w_k (v_k^T x)³

定义四阶对称张量 S[i,j,k,l] = Σ_m w_m[i] · v_m[j] · v_m[k] · v_m[l]
f_i(x) = Σ_(j,k,l) S[i,j,k,l] · x_j x_k x_l

## Jennrich 算法
1. **对称化**：每项 (j,k,l) 按 3! = 6 个排列归一化
   - 三索引全不同：c/6
   - 两相同一不同：c/3
   - 三相同：c
2. **随机收缩**：选随机 a, b ∈ GF(257)^n
3. **构造 A, B**：
   - A[p,q] = Σ_(perms) S_c[idxs] · a[r]
   - B[p,q] = Σ_(perms) S_c[idxs] · b[r]
4. **计算 X = A · B^(-1)**
5. **特征分解**：扫 t ∈ [0,256] 找 det(X - tI) = 0
6. **零空间** 求特征向量 v_k，归一化首非零为 1
7. **解 W**：A_rows = V^∘³ W，W = (V^∘³)^(-1) · A_rows
8. **解 u³ = (W^T)^(-1) · y**（y 是密文向量）
9. **开三次方**：`u = pow(u³, inv3, 257)`，inv3 = 171（因为 3*171 mod 257 = 1）
10. **解 V^T · x = u**，组装 35 个数字 → bytes → FLAG

## 关键技术
- 稀疏张量存储节省内存
- 高斯消元求模 257 矩阵逆
- 多次尝试处理不可逆情况
- 验证每步正确性
- 提前终止避免无效计算
- 缓存中间结果供调试

## 张量密码学背景
- 张量分解 = CP 分解 = Σ v_k ⊗ v_k ⊗ v_k
- Jennrich 算法：随机收缩构造对称矩阵 + 特征分解
- 时间复杂度 O(n³)
- 确定性算法（条件合适时）
- 不需要初始猜测

## 评价
n1ctf Crypto 顶级难度。考察张量分解在密码学中的应用，Jennrich 算法是 1970 年代经典方法但在 GF(257) 立方加密场景下被现代密码分析者武器化。Solved by 顶尖战队。
