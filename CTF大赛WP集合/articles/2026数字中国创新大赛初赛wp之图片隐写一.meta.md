# 2026 数字中国创新大赛初赛 wp 之图片隐写一

## 题目

5 张图，lsb 隐写，范围限制。

## 工具：zsteg

```bash
zsteg --lsb1.png
zsteg -a --lsb1.png
```

## 自写爆破脚本

```python
from PIL import Image
img = Image.open("5.png")
rgb = img.convert("RGB").tobytes()
G = rgb[1::3]  # G 通道 stride
L = 32  # 答案长度

for start in range(0, 8):           # 起始位
    for step in range(1, (len(G) // (L * 8)) + 1):  # 间隔
        bits = [G[start + i * step] & 1 for i in range(L * 8)]
        result = []
        for i in range(0, len(bits), 8):
            b = 0
            for bit in bits[i:i+8]:
                b = (b << 1) | bit  # msb 拼字节
            result.append(b)
        decoded = bytes(result).decode(errors='ignore')
        if decoded.isprintable():
            print(decoded)
```

## 关键
- **G 通道**：`rgb[1::3]` 取 G 通道（试到第二个试出来）
- **start**：从第几位开始存储（0-7 爆破）
- **step**：平均间隔 `len(G) / (L*8)` 上限
- **msb/lsb**：2 种拼字节方式
- **isprintable**：可打印过滤，肉眼判断

## 经验
- LSB 隐写爆破套路：start × step × msb/lsb 三维爆破
- zsteg 处理 90% 常见情况
- 5 张图轮试 5 分钟内出答案
