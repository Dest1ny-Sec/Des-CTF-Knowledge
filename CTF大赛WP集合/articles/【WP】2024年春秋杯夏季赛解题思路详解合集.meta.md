## happy2024 (RSA + AES + HSSP)

### 思路
- RSA 加密 AES key
- AES iv 由矩阵乘法混淆
- 实际是 HSSP (Hidden Sum of Subset Products)
- 用格 (lattice) 打 hint

## Signature (Proof + 排列爆破)

### Proof 爆破
```python
from pwn import *
import hashlib
import string

def proof():
    r.recvuntil(b'Your gift --> ')
    gift = r.recvline()[:-1].decode()
    password = 'happy_the_year_of_loong'
    l = 19
    table = [i for i in range(len(password)) if password[i] in string.ascii_lowercase]
    for i in range(2 ** l):
        pad = bin(i)[2:].zfill(l)
        tmp_list = list(password)
        for j in range(len(table)):
            if pad[j] == '0':
                tmp_list[table[j]] = tmp_list[table[j]].upper()
        payload = ''.join(tmp_list)
        if hashlib.sha256(payload.encode()).hexdigest()[:6] == gift:
            r.recvuntil(b'>')
            return payload
```

## 经验提炼
- ECC 离散对数用 `pow(x2-x1, M-2, M)` 模逆 + c1-k*c2 还原明文
- HSSP (Hidden Sum of Subset Products) 用格 (lattice) 攻击
- 排列爆破 proof 2^19 case 调整大小写
- Sage `EllipticCurve(GF(p), [a, b])` 是 ECC 群
- ECC 加法公式：同点 p = (3x² + a) / 2y，异点 p = (y2-y1) / (x2-x1)
- 基点 base + 私钥 k = 公钥 pub，求 k 即 ECDLP
- RSA+AES 组合加密时 AES key 用 RSA 加密 + iv 用 HSSP 矩阵混淆
- case 爆破：2^19 长度 = 524288 次尝试，sha256 前 6 字符匹配
- 还原 p 后用 Sage 算 m = c1 - k*c2 是经典 ECDLP 还原明文手法
