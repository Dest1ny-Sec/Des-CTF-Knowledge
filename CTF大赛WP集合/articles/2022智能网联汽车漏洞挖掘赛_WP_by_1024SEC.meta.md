## Q2 USB HID 键盘流量
```bash
$ tshark -r usb.pcap -T fields -e usb.capdata > usb.txt
```
- `usb.data_len == 8` 过滤 8 字节 HID
- 8 字节结构：
  - 字节 0：修饰键（Shift/Ctrl/Alt）
  - 字节 1：保留
  - 字节 2：键码

**WangYihang UsbKeyboardHacker.py：**
```python
normalKeys = {
    "04": "a", "05": "b", "06": "c", ..., "1e": "1", "1f": "2", "20": "3",
    "21": "4", ..., "27": "0", "28": "<RET>", "2a": "<DEL>", "2c": "<SPACE>",
    ...
}
shiftKeys = {"04": "A", "05": "B", ..., "1e": "!", "1f": "@", "20": "#", ...}

result = ""
for press in presses:
    if ':' in press:
        Bytes = press.split(":")
    else:
        Bytes = [press[i:i+2] for i in range(0, len(press), 2)]
    if Bytes[0] == "00":
        if Bytes[2] != "00" and normalKeys.get(Bytes[2]):
            result += normalKeys[Bytes[2]]
    elif int(Bytes[0], 16) & 0b10 or int(Bytes[0], 16) & 0b100000:
        if Bytes[2] != "00" and normalKeys.get(Bytes[2]):
            result += shiftKeys[Bytes[2]]
```
