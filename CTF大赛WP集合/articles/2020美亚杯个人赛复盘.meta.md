# 2020 美亚杯个人赛复盘

原文 https://www.ctfiot.com/63974.html （Th0r 安全）

## 案件
Alice 笔记本 + 手机 + USB 三件套取证。**疑似信用卡诈骗**：
- Alice 邮箱 `shy1211@mtzh.gow.tw`
- AP/Bob/Cole 等同伙
- WhatsApp 群组 "Big Big Club"
- 加密 ZIP 发票
- 加密 USB 容器
- 加密 wallet

## 61 问（分类）

### 笔记本取证 (Q1-22)
- SHA-1 hash / OS / SID / 最后登录 / 主机名
- 密码修改时间 / 时区 / 文件系统（NTFS）
- 浏览器（最常用 + 版本 + 历史）
- 在线商店 / 信用卡号 / CSC
- USB IndexerVolumeGuid 时间戳 → 最后插入时间
- ZIP SHA-256 / 修改时间 / 内容

### 邮件取证 (Q23-34)
- 邮件软件（Outlook/Thunderbird）+ 版本
- Alice 邮箱 / Bob 邮箱 / AP 邮箱
- 邮件附件 / IP 头
- 群组间邮件记录
- ZIP 内信用卡数据数量 / 受害人被购买的商品

### 手机取证 (Q35-52)
- 手机型号 / OS 版本 / 总存储
- WhatsApp 图片 IMG-20200929-WA0002 / WA0004 时间
- 元数据 + 相机型号（EXIF）
- Chrome 历史 / Safari / 浏览器 DB
- WhatsApp ID / 账户名
- Bob/Cole 最后聊天时间
- Big Big Club 创建时间表
- WhatsApp Web 登录（UTC+0）
- "Deleted by the sender" 的 media_wa_type
- WiFi MAC 地址

### USB 加密取证 (Q53-61)
- ZIP 密码（部分字符被遮盖）
- 存储秘密数据的程序（VeraCrypt / KeePass / 1Password）
- 秘密消息密码
- 档案类型 / USB SHA-256
- Downloads.7z SHA-256 + 修改时间

## 教学价值
- **美亚杯** 是中文区最大型电子数据取证比赛
- 工具链：FTK Imager / X-Ways / Autopsy / 火眼 / 鲁盒 / iVe
- 三件套：笔记本镜像（E01/DD）+ 手机镜像 + USB 镜像
- 关键技能：
  - 注册表解析（SAM / SOFTWARE / SYSTEM）
  - 浏览器历史解析（Chrome/Edge/Firefox）
  - WhatsApp msgstore.db.crypt14 解析
  - VeraCrypt / KeePass 容器密码爆破
  - Email PST / mbox 解析 + IP 头
  - EXIF 元数据（exiftool / mat2）

## 真实案件线索
- 信用卡诈骗团伙：AP 为主脑，Bob/Cole 是中间人
- 邮件通过 shyl1211@mtzh.gow.tw 沟通
- USB 隐藏 VeraCrypt 容器藏发票 + 加密 wallet 地址
- 笔记本贴密码纸条（物证）
