# 2024 数字中国积分争夺赛 - 线下

## 半决赛

### 1. babysign（DSA LCG PRNG 论文攻击）

参考论文：《"Pseudo-Random" Number Generation within Cryptographic Algorithms: the DSS Case》

```python
def sign(message, sk):
    global state
    new_state = sum([state[i] * c[i] for i in range(t+1)]) % N
    state = [1] + state[2:] + [new_state]
    nonce = new_state
    r = pow(g, nonce, p) % q
    s = inverse(nonce, q) * (sk * r + int(sha256(message).hexdigest(), 16)) % q
    return r, s
```

DSA 6 条签名（消息是 `b"114514"*(i+1)`），PRNG 是 t=3 阶 LCG。

**构造 16x16 矩阵 LLL**：
```python
E1 = 2^320; E2 = 2^200
L = Matrix(QQ, 16, 16)
# 对角填入 s_i, q, N；右上角填入 -c_j
# 第一行放 -r_i；最后一行标度 E2
res = L.LLL()
```

LLL 第一行 → 还原 t[0..4]（LCG 状态倍数）→ `gcd(t[3], t[1])` 约分：
```python
tmp = t[3] * a[1] - t[1] * a[3]   # 即 q*k
tmp = tmp % q
# 多次迭代还原 e1 = tmp * invert(t[3], t[1]) % t[1]
sk = (a[1] + e1) * invert(t[1], q) % q
```

**Babai's Closest Plane Algorithm** 把 LLL 输出贴近期望向量 Y：
```python
Y = vector([m0, m1, ..., m5, c0, c0, c0, 1, 1, 1, 1, 1, 1, 1])
X = BabaisClosestPlaneAlgorithm(L_lll, Y)
sk = X[-1] * E2
```

最后用 `md5(sk)` 当 AES 密钥解 `enc`：
```

```

### 2. 双层 RSA（Boneh-Durfee small prime comb）

```python
def gen_keys1():
    while True:
        try:
            p = getPrime(512)
            q = next_prime((p + randint(0, 2**360))//2*3)   # q ≈ p * 1.5
            n = p*q
            d = randint(n**0.314, n**0.324)                 # 小 d
            e = inverse(d, phi)
            break
        except: continue
    return e, n

def gen_keys2():
    while True:
        try:
            p = getPrime(510)
            q = next_prime(p + randint(0, 2**(low_bits-104)))  # q 与 p 共享低 104 bit
            n = p*q
            d = randint(n**0.39, n**0.40)
            e = inverse(d, phi)
            break
        except: continue
    return e, n
```

**第一层 (i=2, j=3)**：q 与 p 比例 3:2
**第二层 (i=1, j=1)**：q-p < 2^(low_bits-104)，low_bits=360

```python
def attack_rsa_with_small_prime_comb_and_small_pri(i, j, e, n):
    for kd in continued_fraction(e/(n - isqrt(i/j*n) - isqrt(j/i*n) + 1)).convergents():
        tk, td = kd.numerator(), kd.denominator()
        if int(pow(2, e*td, n)) == 2:  # 验证 2^(e*td) ≡ 2 (mod n)
            print("d =", td); return td

d2 = attack_rsa_with_small_prime_comb_and_small_pri(1, 1, e2, n2)
d1 = attack_rsa_with_small_prime_comb_and_small_pri(2, 3, e1, n1)
c1 = pow(c2, d2, n2)
# c1 may bigger than n2, iterate k
for k in range(100):
    m = pow(int(c1) + k*n2, d1, n1)
    flag = long_to_bytes(int(m))
    if b"flag" in flag: print(flag)
# flag{e8d4abc6c676f92e2f4874973d25c420}
```

**关键**：continued_fraction 收敛子 + `2^(e*td) ≡ 2 (mod n)` 验证是 Boneh-Durfee small private exponent 的标准验签。
