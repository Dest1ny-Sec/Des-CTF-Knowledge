### 题目详情

**1. runes (MIPS)**
- mmap一段内存,任意使用syscall
- chroot逃逸:经典 `mkdir foo; chroot foo; cd ..` 或 `chroot("."); cd ../../../../../../../../flag`

**2. stack use-after-scope (朴素寄存器分配)**
```c
case IR_CALL: {
    cprintl("addi $sp,$sp,-%d", ir->in_cnt * 4);
    for (int i = 1; i <= ir->in_cnt; ++i) {
        cprintl("sw $%d,%d($sp)", op2reg(&ir->ops[i]), 4 * (i - 1));
    }
    flush_cache();// 在这里刷新寄存器,写回内存
    ...
    reset_cache();
    int wr = reg_for_write(ir->out.var->off);

    break;
}
```
- 结构体返回到ra寄存器覆盖
- 时间侧信道:exit_code -11(SIGSEGV) vs -31(SIGSYS)
