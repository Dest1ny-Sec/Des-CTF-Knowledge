# 比赛中遇到的一些简单的逆向题目

**性质**：6关CrackMe ELF逆向WP（2022）

**6关详解**：

**Check1**：长度校验
```c
if (strlen(a1) != 34) { puts("失败"); exit(1); }
```

**Check2**：前缀校验
```c
if (strncmp(a1, "flag{", 5)) { puts("失败"); exit(1); }
```

**Check3**：末位校验
```c
if ((_BYTE)a1[strlen(a1) - 1] != 125) { puts("失败"); }  // 125 = '}'
```

**Check4**：第一段（_分隔）
- 找_位置 → 长度 = `(v4 - 5) / 2`
- 十六进制位运算：每2字符 → v1（高4位）+ v2（低4位）→ `s1[i] = v2 | 16*v1`
- 数字字符减48，a-f字符减87
- 目标字符串 `olympics`
- 爆破脚本：枚举v1, v2 ASCII

**Check5**：第二段
- `s1[i] = a1[i] ^ (i&1 ? 33 : 32)`
- 目标字符串 `in` → 异或32/33得 `IO`（I=73^32=105='i', O=79^33=110='n'）
- 作者电脑上卡在第5关，换Ubuntu后正常（疑为环境差异）

**Check6**：第三段（后段逻辑）

**关键技术**：
- 多关CrackMe三段式：长度+格式+内容
- _分隔字符串处理
- 位运算十六进制转字符
- 32/33交替异或

**质量评估**：中（思路清晰，第三段payload不完整）
