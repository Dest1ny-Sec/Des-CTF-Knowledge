# 第一届数证杯个人赛—流量取证手搓版

**来源**: ctfiot.com ID 218849
**难度**: 中等（介于 CTF 和一般流量取证之间）
**工具**: CTF-NetA（GitHub 免费版 + 付费版）

## 提示序列
```
84、104、33、115、95、49、115、95、53、101、99、114、101、116、33
```

`chr()` 转 ASCII：
```
T h ! s _ 1 s _ s e c r e t !
```

→ "Th!s_1s_secret!" 是密钥协商提示

## 冰蝎1（Behinder）流量分析

### 阶段 1：密钥协商
1. 攻击者通过 GET/POST 请求形如 `http://xx.xxx.xx.xx/shell.aspx?pass=645`
2. 服务器使用随机数 MD5 的高 16 位作为密钥
3. 存储到 `$_SESSION` 变量并返回密钥给攻击者

### 阶段 2：加密传输
1. 客户端把待执行命令作为输入
2. 利用 AES 算法或 XOR 运算加密，发送至服务端
3. 服务端解密执行
4. 执行结果通过 AES 加密后返回

## 解题思路
1. 用 Wireshark 过滤 HTTP 流量
2. 识别 `shell.aspx?pass=XXX` 模式
3. 提取密钥协商响应（MD5 高 16 位）
4. 对后续加密流量做 AES/XOR 解密
5. 还原执行的命令

## 工具推荐
- **CTF-NetA**（GitHub 免费版 + 付费版）
- Wireshark + tshark
- CyberChef（多算法编解码）
- Python 自定义解密脚本

## 评价
流量取证入门题，难度介于 CTF 和一般流量取证之间。冰蝎1 识别 + AES/XOR 解密是基础技能。提示序列"Th!s_1s_secret!"作为密码学入门教学合适。
