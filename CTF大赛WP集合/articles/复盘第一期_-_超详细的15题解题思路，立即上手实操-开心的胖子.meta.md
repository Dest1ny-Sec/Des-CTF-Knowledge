### Q11 数据库还原 + AES 解密
```python
import mysql.connector
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad
from base64 import b64decode

conn = mysql.connector.connect(host='localhost', user='root',
                                password='root', database='telefram')
key = 'G7YQ1BWBU0RV018S'.encode()
iv = 'QTLNDWGER2P8IRG7'.encode()

def decrypt(enc):
    cipher = AES.new(key, AES.MODE_CBC, iv)
    return unpad(cipher.decrypt(b64decode(enc)), 16).decode()

cursor = conn.cursor()
cursor.execute("SELECT message FROM message")
for (msg,) in cursor.fetchall():
    print(decrypt(msg))
```

## 教学
- 涉网犯罪复合型: 流水+调证+APK+爬虫+SQL+AES+XSS+RCE
- Electron preload.js execCommand 是 XSS→RCE 通道
- this.parent.chatClientApi 是嵌套框架上下文
- NATAPP 双隧道 (TCP+Web) 是 XSS 反弹 shell 必备
