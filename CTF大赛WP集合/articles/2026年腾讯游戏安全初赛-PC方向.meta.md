# 2026 年腾讯游戏安全初赛-PC 方向

## 题目：SHAD0WNT_HYPERVMX

**flag{SHAD0WNT_HYPERVMX}**

### 题目结构

游戏 = 用户态 `ShadowGateApp.exe` + 内核驱动 `ShadowGateSys.sys`

- 13x13 迷宫，Entry=(0,0)，Exit=(12,12)
- 命令：W/A/S/D 走上下左右，I/J/K/L 走 alt 方向，R 重置，T 显示操作日志

### 关键 API

**用户态 → 驱动通信**：
```c
__int64 OpenShadowGateDevice() {
    result = CreateFileW(L"\\\\.\\ShadowGate", 0xC0000000, 0, 0, 3u, 0x80u, 0);
    if (result == -1) {
        LastError = GetLastError();
        // ERROR_INVALID_NAME (2) → 驱动未加载
        // ERROR_ACCESS_DENIED (5) → 需管理员
    }
    return result;
}
```

**创建命名事件**：
```c
HANDLE CreateLeakEvents() {
```

**迷宫查询 IOCTL**：

**驱动关键 sub_140316ADF**：

### 攻击思路

- 每次走子，驱动写 `TEB->LastErrorValue` = handle_ok
- 5 次成功移动 → 暴露 5 比特（顺序固定）
- 每 5 次 reset → 重复获取 5 比特
- 走通迷宫 → 拿 Shadow 内部网络凭据

### 命名事件反馈
- `Global\MazeMoveOK`：成功事件
- `Global\MazeMoveWall`：失败/撞墙事件
- 驱动 `ZwOpenEvent + ZwSetEvent` 触发

### 类型对比
| 类型 | 对象名 | 含义 |
|------|--------|------|
| 命名事件 | GlobalMazeMoveOK | 成功反馈 |
| 命名事件 | GlobalMazeMoveWall | 失败/撞墙反馈 |
| 命名信号量 | （待解码） | 成功反馈 |
| 线程用户态上下文回写 | TEB +0x68 | handle_ok 状态 |

## 总结
腾讯游戏安全 = 内核驱动 + 用户态逆向 + 反作弊绕过；SHAD0WNT_HYPERVMX 用 TEB+0x68 (LastErrorValue) 隐式状态回写 + 命名事件双重泄露路径。
