## 题目详解

### 1. RSA 小素数
```python
from libnum import n2s, s2n

p = 1267650600235241044365044382487
q = 1267650600260888172240281085029
e = 65537
c = 1566077545968868311749088444723100549024925747577903610033503

# modinv + pow(c, d, n) + n2s(m)
```
- p, q 已知（题目直接给）
- n = p*q 不超 66 位，普通 pow 即可还原
- 关键点：直接拿题目给的 p, q，跳过因式分解

### 2. MD5 前缀爆破
```python
s = '0123456789!@#$%^&*`~()_+-=[]{};:,.<>?/'"\|'
for i in s:
    for j in s:
        for k in s:
            for l in s:
                for m in s:
                    c = str(i) + '1_1001_10_600_600_' + str(j) + str(k) + '00' + str(l) + str(m) + '7_202103301539'
                    md5 = hashlib.md5()
                    md5.update(c.encode('utf-8'))
                    d = md5.hexdigest()
                    if d[:4] == 'b9fd' and d[6:9] == '9d5':
                        print(c, d)
```
- 5 字节 printable 暴力枚举（约 95^5 ≈ 77 亿次偏大）
- 实际可用 z3 / 字典前缀缩小到 2-3 字节

## 关键技巧
- **RSA 小素数**：题目直接给 p, q 是入门题标志
- **MD5 前缀爆破**：4-6 字符前缀爆破速度可控
