# 2025 能源 CTF

## Q1: RSA 隐 p（线性同余）

```python
from Crypto.Util.number import *
import hint

flag = b'xxx'
e = 65537
p = getPrime(512)
q = getPrime(512)
n = p*q
m = bytes_to_long(flag)
c = pow(m, e, n)
k = getPrime(1024)
assert hint + 233 * k == 233 * k * p  # → p | hint
print(n); print(c); print(hint)
```

**攻击**：`hint + 233*k == 233*k*p` → `233*k*p - 233*k = hint` → `233*k*(p-1) = hint` → `p-1 = hint / (233*k)`  
但 k 未知 → 试不同 k → `gcd(hint, 233*k)` → 当 hint 整除 233*k 时 p = hint/(233*k) + 1 是 512 bit 质数。

## Q2: HNP 隐数问题格攻击

```python
from Crypto.Util.number import *
from secrets import flag

assert len(flag) == 38

p = getPrime(512)
m = getPrime(512)
while m > p: m = getPrime(512)

aa, cc, bb = [], [], []
for i in range(30):
    a = getPrime(512)
    b = getPrime(400)
    c = (a * m + b) % p
    aa.append(a); cc.append(c); bb.append(b)

enc = pow(m, flag, p)
print(f'p = {p}')
print(f'aa = {aa}')
print(f'cc = {cc}')
print(f'enc = {enc}')
```

**核心观察**：
- `c_i = a_i * m + b_i mod p`
- m 是 512 bit，p 是 512 bit，b_i 仅 400 bit
- 共 30 组线性方程 → **HNP（Hidden Number Problem）**

**格构造**：
```
[p 0 ....        ]
[0 p ....        ]
[   ....        ]
[a a .... K/p    ]
[c c ....      K ]
```

```python
length = len(aa)
target_vector_length = 400
K = 2**target_vector_length

a = []
for i in range(length):
    b = []
    for j in range(length):
        if i == j: b.append(p)
        else: b.append(0)
    b.append(aa[i])
    a.append(b)

# 末行 c
last_row = [cc[i] for i in range(length)] + [0, K]
a.append(last_row)

# 倒数第二行 K/p
second_last = [K/p for i in range(length)] + [0, 0]
a.append(second_last)

M = Matrix(ZZ, a)
L = M.LLL()
# 找还原的 m
```

**关键参数**：
- `target_vector_length = 400`（b 的位长）
- `K = 2**400`
- `K/p` 让 a_i 行归一化
- LLL 找到最短向量 = m 的倍数
