# 2023 研究生国赛华为杯 4 题 WP

**一、easy_xor**

IDA 打开后 main 函数残缺，识别到 `call $+5` 指令（动态调自己的下一条地址做 `pop ebp` 拿 EIP），是常见花指令混淆。

```asm
.text:00401560 83 C4 04          add esp, 4
.text:00401563 55                push ebp
.text:00401564 E8 00 00 00 00    call $+5     ; 拿到 0x401569
.text:00401569 5D                pop ebp
.text:0040156A 48                dec eax      ; 0x401569 → 0x401568 (text段)
```

NOP 掉 0x401560~0x4015B8 的混淆，重新 F5 后看到 `init(v13, v9, 46, v14)` 和 `enc(v9, xor_array)` 两个函数都跟输入无关。动调拿到：

**二、T4ee（6 part 树形混淆 + 反调试）**

真实逻辑拆成 6 part 插入二叉树，val2/val3 控制 run 顺序。`check_debug` 函数把 val2=1, val3=0（反调试）。

实际执行顺序是 part1→2→4→5→3→6（输入→长度→打乱→RC4→异或链→密文比对）：

```python
from Crypto.Cipher import ARC4
c = [0x2C, 0x40, 0xCE, ... 0xB1]   # 34 字节密文
# part3 倒序异或链
for i in range(len(c)-1, 0, -1): c[i-1] ^= c[i]
# part5 RC4
rc4 = ARC4.new(key=b'GoodLuck')
c = rc4.decrypt(bytes(c))
# part4 打乱索引复原
box = [4,19,9,1,24,14,5,0,18,31,21,16,11,29,12,2,30,13,3,15,8,7,17,32,33,6,25,20,26,10,23,22,27,28]
flag = [0]*34
for i in range(34): flag[box[i]] = c[i]
```

flag = `flag{T4ee_Travel_M@kes_me_H@ppy!!}`

**三、lin（Golang 闯关）**

主菜单 3 选项，输入要 29 字符 `DASCTF{hasaki-pdtzptz-vxnfnu}` 形式。IDA 找 base64 字符表：

```go
lea rbx, aReftq1rge2hhc2 ; "REFTQ1RGe2hhc2FraS1wZHR6cHR6LXZ4bmZudX0="
// 与 runtime_memequal 比较 0x28 字节
```

3 关：
- 第一关：`unfnxv` 经 rot13 解密得 `hasaki`（6 字节）
- 第二关：动调到 `runtime_memequal` 比 `vxnfnu`（输入就是这个）
- 第三关：把 base64 比对前的中间结果拦下来，发现我们输入 `pdtzptz` 变成 `uiyeuye`（每位差 5，凯撒）

最终 `DASCTF{hasaki-kyoukou-vxnfnu}`。

**四、Robbie gave up（Unity 游戏）**

Robbie gave up_Data/Managed/Assembly-CSharp.dll 用 dnSpy 打开：

```csharp
public static object Win() {
    for (int i = GameManager.instance.orbs.Count; i < Robbie.data1.Length; i++) {
        Robbie.data2[i] = (byte)(Robbie.data1[i] ^ i);
    }
    Type type = Assembly.Load(Robbie.data2).GetType("ClassLibrary1.Class1");
    return type.GetMethod("Method").Invoke(type.GetConstructor(Type.EmptyTypes).Invoke(new object[0]), null).ToString();
}
```

`data1[i] ^ i` 还原成 DLL 字节 → Assembly.Load → 调用 `Method()`：

