Security Camp 2023（セキュリティキャンプ 2023）讲师参加记（中日语对照，来源 ctfiot）。

**主要内容**
- L1 加密通信研讨班：Primitive 课程 + Protocol 课程
- Protocol 课程讲师视角的教学经验
- TLS 1.3 实现 + UDP over TLS 隧道（VPN over WireGuard 通过 DNS/HTTP/HTTPS）
- 引用 Adler 心理学 / Coaching 技法

**教学理念**：
- 讲师是引导者，不是答案给予者
- 学员自己找目的、目标、手段
- "成为互联网之海的开拓者"

**质量评估**：这是教学经验记录，不是 CTF WP。标 low，仅作日本 Security Camp 入门参考。
