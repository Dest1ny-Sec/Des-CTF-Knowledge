# 2025 西湖论剑·网络安全大赛 WP

## Web

### Rank-l（Flask SSTI 绕黑名单）

```python
from flask import Flask, request, render_template, render_template_string, redirect, url_for, abort
from urllib.parse import unquote

app = Flask(__name__)
phone = ''

def is_safe_input(user_input):
    # 关键字黑名单
    unsafe_keywords = ['flag', '?', '*', '-', 'less', 'nl', 'tac', 'more', 'tail', 'od', 'grep', 'awd', 'sed', '64', '/', '%2f', '%2F']
    if any(keyword in user_input for keyword in unsafe_keywords):
        return True
    return False

@app.route("/login", methods=["POST"])
def login():
    global phone
    phone = request.form.get("phone_number")
    return render_template("login.html")

@app.route("/cpass", methods=["POST"])
def check():
    global phone
    password = request.form.get("password")
    if is_safe_input(phone):
        return redirect(url_for('index'))
    if phone != "1686682318" and password != "Happy_news_admin":
        return render_template_string('...<script>alert("{}The number does not exist or the password is incorrect!")</script>...'.format(phone))
    else:
        return redirect(url_for('index'))
```

**注入点**：`/cpass` 的 `render_template_string` 把 `phone` 直接格式进 HTML。

**绕黑名单**：
- 黑名单有 `nl` / `tac` / `more` / `tail` 等 → 改用 `os.popen` 调用
- `nl flagf149` 黑名单（nl 关键字）→ `'CD ..;NL FLAGF149'.lower()` 大写化后 lower → `cd ..;nl flagf149`（小写后绕过黑名单）
- `flag` 黑名单 → 改读 `flagf149` 之类
