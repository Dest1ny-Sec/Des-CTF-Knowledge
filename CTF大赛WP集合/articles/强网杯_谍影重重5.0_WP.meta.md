# 强网杯 谍影重重5.0

原文 https://www.ctfiot.com/213700.html

## 步骤
1. **tshark 抓 NTLMSSP 字段**
   ```bash
   tshark -n -r dy.pcapng -Y 'ntlmssp.messagetype == 0x00000003' -T fields \
     -e ntlmssp.auth.username -e ntlmssp.auth.domain \
     -e ntlmssp.ntlmv2_response.ntproofstr -e ntlmssp.auth.ntresponse
   ```
   拿到 `tom::.:c1dec53240124487:ca32f9b5b48c04ccfa96f35213d63d75:...`
2. **hashcat 跑 rockyou 字典** → 爆破出 `babygirl233`
3. **NTLM 会话密钥推算**
   ```python
   passwordHash = MD4(utf-16-le "babygirl233")
   responseKey  = HMAC-MD5(passwordHash, (TOM + .).encode('utf-16-le'))
   keyExchangeKey = HMAC-MD5(responseKey, ntProofStr)
   sessionKey   = ARC4(keyExchangeKey).decrypt(encryptedSessionKey)
   ```
4. **解密 SMB 流量** 取后续文件
5. **RDP 键盘还原**
   ```bash
   tshark ... -Y 'rdp.fastpath.scancode.keycode' -T fields -e ...
   ```
   键码 `0x02-0x53` 映射字符表 + shift 状态 → 还原攻击者输入的 flag/命令

## 教学要点
- NTLMSSP 三步握手（type 1/2/3）字段定位
- 离线 hashcat 爆破 NTLMv2 response 不需主动认证
- ARC4 是 NTLM 加密会话密钥的"老"算法，可手算
- RDP fastpath 走 scancode 模式，键码 + shift 还原字符
