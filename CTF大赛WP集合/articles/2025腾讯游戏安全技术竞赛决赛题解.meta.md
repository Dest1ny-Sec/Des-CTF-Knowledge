# 2025 腾讯游戏安全技术竞赛 - 决赛题解

## 速读
作者 xia0ji233 — Windows 驱动 + VT 抗分析的复合逆向题，附 4 个工具源码 (XSafe/XSafe2/VT-Detection1/VT-Detection2) + exp.py。

## 抗分析链路
1. 检测 kdcom.dll 模块 → 找到就 'ACE' 蓝屏
2. 后台线程循环 KdDisableDebugger
3. 读 flag → 单表替换 (VT hook +0x95DF)
4. 用输入 key XOR flag
5. 启用 VT 改写过的 TEA 加密
6. VT hook rdmsr(0xE8) → 在 check 前 XOR 一个 key (key 由 flag 长度决定)

## 工具链
- **XSafe.sys**: 加载顺序辅助 (后加载题目驱动)
- **XSafe2.sys**: 定位 TEA 函数，dump enc.bin
- **VT-Detection1.sys**: MSR 检测源码 (虚机+真机均有效)
- **VT-Detection2.exe**: 真机专属检测
- **exp.py**: Unicorn 模拟 0xFFFFF806FF8D9F0C..A05C 函数，hook 0xA05C 处读 RSP+0xE0 栈明文

## 算法逆推
- `dfs(44, 22)` 用记忆化 f[x][y] = x%5 + dfs(x-1,y) + dfs(x-1,y-1)
- 结果: 7039739125714

## 检测规避
- hook NtQuerySystemInformation 在 SystemModuleInformation 时把 kdcom.dll 的 Name[0] 改 'x'
- 通过 RtlWalkFrameChain 检测栈回溯里是否有 Hooks 范围内地址
