# 2024 龙信杯计算机取证 - t.wnry 解密后 dll MD5

## 题目
**分析计算机检材，接上题，请问恶意程序解密了 t.wnry 后该 dll 的 md5 值是多少。**  
[标准格式：全大写]

## 思路

1. **样本分析**：拿到 WannaCry 变种样本，IDA / Ghidra 静态分析入口点。  
2. **解密流程跟踪**：动态调试（x64dbg / WinDbg）跟踪恶意程序解密 t.wnry 的流程。  
3. **dll 提取**：解密后释放的 dll（一般含加密功能或 C2 通信）导出到磁盘。  
4. **MD5 计算**：`certutil -hashfile decrypted.dll MD5` 或 `md5sum`。  
5. **格式**：标准格式 = 32 字符十六进制全大写。

## 关联技术
- WannaCry 利用 EternalBlue 漏洞 + DoublePulsar 后门  
- 加密 .wnry 文件使用 RSA + AES 混合加密  
- 解密 dll 往往是 loader 或 C2 模块
